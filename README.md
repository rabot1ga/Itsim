# 💻 IT Life Simulator v2.0

**Telegram Mini App** — юмористический симулятор жизни IT-специалиста.

> «Блин, это буквально мой прошлый вторник.»

Симулятор жизни айтишника в формате Telegram Mini App. Игрок начинает после института и строит карьеру, управляя ресурсами, расписанием и решениями.

## 🚀 Быстрый старт

```bash
npm install
npm run dev
```

Сервер: `http://localhost:3001`  
Клиент: `http://localhost:5173`  
Бот: `http://localhost:3002`

## 🏗️ Архитектура

```
it-life-simulator/
├── packages/
│   ├── shared/          # Общий движок (типы, формулы, логика)
│   ├── content/         # Контент в JSON (события, компании, навыки)
│   ├── server/          # Fastify API сервер
│   ├── client/          # React + Tailwind клиент
│   ├── bot/             # Telegram Bot
│   └── sim/             # Симулятор баланса (40 прогонов × 365 дней)
```

### Стек
- **Frontend:** React + TypeScript + Tailwind + Zustand
- **Backend:** Node.js + Fastify
- **Telegram:** Mini App SDK
- **Контент:** JSON + Zod валидация
- **Симуляция:** 40 прогонов × 365 дней в CI

## 🎮 Основные механики

### Ресурсы
| Ресурс | Роль |
|---|---|
| 💰 Деньги | Ограничитель early game |
| ❤️ Здоровье | Долгосрочный ресурс |
| 🔥 Мотивация | Краткосрочный ограничитель |
| ⚡ Энергия | Ресурс хода |
| ⭐ Репутация | Гейт карьеры |

### Ключевые фичи
- **Offline-прогресс:** энергия копится офлайн (1 день / 3.5 часа, макс 7)
- **Сервер-авторитет:** все расчёты на сервере, клиент — только UI; отклики → собеседования → офферы → повышения
- **Цепочки событий:** события имеют продолжение через N дней (`chainOnly` события не попадают в случайный пул)
- **Система отношений:** NPC с эффектами на события
- **Античит:** rate limiting, серверный RNG, идемпотентные действия
- **Персистентность:** состояние игрока хранится в `packages/server/data/` (JSON, атомарная запись) — переживает рестарты. В проде заменяется на PostgreSQL + Prisma (см. SPEC)

## 🛵 Подработки, майнинг и дерево талантов

- **Подработки (не IT):** курьер, бариста, грузчик, таксист, ночной охранник,
  репетитор (платит от уровня навыка), стример — 1 в день, цена — энергия/здоровье/мотивация
- **Майнинг-ферма:** пассивный крипто-доход. Оборудование (видеокарта → ферма → ASIC),
  электричество, солнечные панели (−50% к счету), волатильный курс (детерминированный шум)
- **Дерево талантов:** 34 навыка в 9 ветках — frontend, backend, mobile, qa, devops,
  **ai_ml, cybersec, gamedev, blockchain** (Solidity, Web3, Rust для Solana, DeFi…)
- **Перки:** 8 шт, включая «Золотую лихорадку» (+15% к майнингу) и «Подработчика» (+20% к гигам)
- **Ачивки:** 17 шт — «Подпольный майнер» (100k с фермы), «Криптокит» (1M)

## 🎨 Процедурная генерация и Solana

Дополнение к ТЗ: [DESIGN.md](DESIGN.md) — стратегия визуала (комбинаторика слоёв + тинтинг)
и интеграция с Solana (on-chain seed, NFT-предметы, cross-collection синергия).

- **Генетика:** детерминированный `sha256`-seed от кошелька → трейты (глаза, причёска, стены…)
- **Слоистый аватар и комната:** HashLips-style манифесты + тинтинг через CSS filter
  (экран «Дом»; слои-плейсхолдеры генерируются `tools/generate_layer_assets.py`)
- **NFT-предметы (мок):** покупка Herman Miller/MacBook → минт Metaplex-style metadata
  в локальный реестр (`packages/server/data/nft_registry.json`), инвентарь в кошельке
- **Cross-collection (мок):** SMB Gen2 → +5% к фрилансу, Mad Lads → постер, DeGods → пёс
- **Шар-карточка:** Canvas-рендер комнаты + статистики → PNG → шеринг в Telegram
- **Прод:** заменить `MockNftProvider` на Helius RPC (интерфейс уже готов)

## 📝 Контент

Весь контент лежит в `packages/content/` в формате JSON:
- `events/` — игровые события (120 шт: daily, work, health, family, погода, NPC-истории,
  startup- и кот-цепочки, mining, курьерские будни, по 2 события на каждую ветку навыков,
  34 события-последствия действий — в 11 файлах)
- `companies.json` — 10 компаний
- `skills.json` — 19 навыков в 5 ветках
- `items.json` — предметы и курсы
- `npcs.json` — NPC персонажи
- `achievements.json` — 15 достижений
- `perks.json` — 6 перков

## ✨ Перки, ачивки и таланты

- **Перки:** 8 шт с реальными эффектами — энергия, скорость обучения, +% к фрилансу/майнингу/подработкам.
  Открываются в «Навыках» при выполнении требований (учитываются ветки дерева)
- **Выбор основного навыка:** тап по навыку в дереве — учёба/работа качают именно его
  (заблокированные ветки гейтятся на сервере)
- **Английский:** бесплатные уроки и платный курс — прокачивает soft-скилл, который
  открывает зарубежные компании
- **Банк офлайн-дней:** накопленные дни можно тратить на полную энергию (+10 🔥)
- **Ачивки:** экран «Трофеи» с 17 достижениями и прогресс-барами

## ✅ Проверки

```bash
npm run lint      # типизация всех пакетов (tsc)
npm test          # юнит-тесты движка (vitest) + симулятор баланса (--check)
npm run build     # полная сборка (shared → server → client → bot → sim)
```

Симулятор (40 агентов × 365 дней) проверяет вехи из таблицы выше
и падает с ненулевым кодом, если баланс вышел из коридоров.

CI (GitHub Actions, `.github/workflows/ci.yml`): lint → test → build
на каждый push в main и каждый PR.

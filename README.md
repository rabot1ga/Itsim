# 💻 IT Life Simulator v2.0

**Telegram Mini App** — юмористический симулятор жизни IT-специалиста.

> «Блин, это буквально мой прошлый вторник.»

Симулятор жизни айтишника в формате Telegram Mini App. Игрок начинает после института и строит карьеру, управляя ресурсами, расписанием и решениями.

## 🚀 Быстрый старт

```bash
npm install
npm run dev
```

Сервер: `http://localhost:3001`  
Клиент: `http://localhost:5173`  
Бот: `http://localhost:3002`

## 🏗️ Архитектура

```
it-life-simulator/
├── packages/
│   ├── shared/          # Общий движок (типы, формулы, логика)
│   ├── content/         # Контент в JSON (события, компании, навыки)
│   ├── server/          # Fastify API сервер
│   ├── client/          # React + Tailwind клиент
│   ├── bot/             # Telegram Bot
│   └── sim/             # Симулятор баланса (40 прогонов × 365 дней)
```

### Стек
- **Frontend:** React + TypeScript + Tailwind + Zustand
- **Backend:** Node.js + Fastify
- **Telegram:** Mini App SDK
- **Контент:** JSON + Zod валидация
- **Симуляция:** 40 прогонов × 365 дней в CI

## 🎮 Основные механики

### Ресурсы
| Ресурс | Роль |
|---|---|
| 💰 Деньги | Ограничитель early game |
| ❤️ Здоровье | Долгосрочный ресурс |
| 🔥 Мотивация | Краткосрочный ограничитель |
| ⚡ Энергия | Ресурс хода |
| ⭐ Репутация | Гейт карьеры |

### Ключевые фичи
- **Offline-прогресс:** энергия копится офлайн (1 день / 3.5 часа, макс 7)
- **Сервер-авторитет:** все расчёты на сервере, клиент — только UI; отклики → собеседования → офферы → повышения
- **Цепочки событий:** события имеют продолжение через N дней (`chainOnly` события не попадают в случайный пул)
- **Система отношений:** NPC с эффектами на события
- **Античит:** rate limiting, серверный RNG, идемпотентные действия
- **Персистентность:** состояние игрока хранится в `packages/server/data/` (JSON, атомарная запись) — переживает рестарты. В проде заменяется на PostgreSQL + Prisma (см. SPEC)

## 📝 Контент

Весь контент лежит в `packages/content/` в формате JSON:
- `events/` — игровые события (21 шт, включая цепочки)
- `companies.json` — 10 компаний
- `skills.json` — 19 навыков в 5 ветках
- `items.json` — предметы и курсы
- `npcs.json` — NPC персонажи
- `achievements.json` — 15 достижений
- `perks.json` — 6 перков

## ✅ Проверки

```bash
npm run lint      # типизация всех пакетов (tsc)
npm test          # юнит-тесты движка (vitest) + симулятор баланса (--check)
npm run build     # полная сборка (shared → server → client → bot → sim)
```

Симулятор (40 агентов × 365 дней) проверяет вехи из таблицы выше
и падает с ненулевым кодом, если баланс вышел из коридоров.

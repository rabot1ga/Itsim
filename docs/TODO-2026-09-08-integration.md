### Почему не слит de8fa8b

Этот коммит меняет старый симулятор и добавляет `maxSkillLevel`, которая уже
есть в main. Его баланс предшествует действующим карьерным воротам. Девять
событий отсутствуют по ID, но используют старую форму эффектов `skill.devops`
вместо `skill: { devops: ... }`. Нужен выборочный перенос контента с миграцией
схем и проверкой 12 добавленных предметов, а не merge старого баланса.

## Обзор пакетов и риски

- **shared:** движок карьеры, дней, навыков, событий; из #6 включены check-in,
  спринты, архетипы и meta-прогресс. 180 тестов проходят.
- **content:** 205 событий, 34 навыка, 33 предмета, 6 архетипов, 3 темы спринта.
  Найдена ошибка TS18046 в проверке unlockAt: тестовый запуск через tsx её
  пропускал, production build падал. Добавлена проверка числового требования.
- **client:** React/Zustand/Vite, изометрическая комната, SVG/pixel-компоненты.
  Карточная база из #6 полезна, но крупные округления и эмодзи пока отличаются
  от референсов. EventCard выделен из DayView для независимого тестирования.
- **server:** Fastify, файловые JSON-сейвы; `routes/game.ts` — 2373 строки.
  Масштабирование хранения и разбиение обработчиков остаются отдельными задачами.
  Привязка NFT-кошелька проверяет формат адреса, не подпись владения; интеграция
  провайдера сейчас mock. Не считать готовой on-chain-функцией.
- **bot:** команды/API-клиенты, 22 теста. Живой Telegram и платежи не проверены:
  preview запускается без токена в dev-режиме, не предназначен для production.
- **sim:** 40 агентов × 365 дней; все балансные проверки проходят.
- **tools:** pixelgen/isogen/uigen, генераторы ассетов. Генерацию полного каталога
  заново не запускал; typecheck и lint соответствующих путей входят в общие команды.
- **CI:** workflow пока лежит в `ci/`, не `.github/workflows/`; автоматические
  проверки GitHub не включены этим изменением. В `ci/README.md` описано ограничение
  прав предыдущего подключения — актуальные workflow-права не проверялись.
- **Зависимости:** npm audit сообщил 8 уязвимостей: 2 moderate, 5 high, 1 critical.
  Затронуты esbuild, fast-uri, fastify, find-my-way, sharp, vite, vite-node,
  vitest. Нужна отдельная совместимая миграция; `audit fix --force` не применялся.

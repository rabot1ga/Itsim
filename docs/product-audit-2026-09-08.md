## 1. Геймплей: как устроено сегодня и чего не хватает

### 1.1. Петли (что есть)

| Петля        | Механика                                                                           | Сильное место                                                             | Слабость                                                                                         |
| ------------ | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Дневной цикл | День = 16–20 энергии, действия (учёба/работа/отдых/соц.), конец дня                | Действия читаемы, цены/энергия на видном месте, «стоимость дня» объяснена | Нет цели сессии: «что мне делать сегодня» — только задание дня (рандом) и карточка грейда        |
| Рост навыков | Учёба → XP → уровень; ветки с гейтами; основной навык                              | Дерево-«галактика» (PoE) — уже отлично                                    | Нет «билдов»/архетипов («fullstack-путь»), нет поощрения глубины в UI поверх гейтов              |
| Карьера      | Грейды intern→CTO через гейты (глубина навыка + софт)                              | Гейты видны в карточке                                                    | Нет промежуточных «событий найма» после получения оффера? (есть квиз)                            |
| Экономика    | Деньги: зарплата − расходы − аренда − налог; источники: фриланс/подработки/майнинг | «Стоимость дня» и баланс в HUD                                            | Мало крупных «стоков» на позднем этапе: после пентхауса деньги почти не на что тратить           |
| Жизнь        | Энергия/здоровье/мотивация, события-выборы, выгорание                              | 205 событий-выборов — богато                                              | События без таймера: оффер может «висеть» вечно → нет срочности                                  |
| Мета         | Ачивки (17), перки (8), рейтинг, лидерборд, банк офлайн-дней, CTO-выборы, финалы   | Рейтинг сквозной                                                          | Нет «престижа»/ресета, нет сезонов, нет ежедневного стрика/входа, нет событий-ивентов по времени |
| Дом          | Комната + мебель + питомцы + гардероб                                              | Сильный визуальный слой, смена жилья меняет сцену                         | Нет «цели» для дома после заполнения: нет коллекций-сетов с бонусами                             |

### 1.2. Диагноз по «экономике жанра» (источник: фреймворк sinks/sources)

Идл-игры держатся на 4 ресурсах: время (мягкая валюта), **энергия = «поводок»**, накопленный
прогресс и «престиж». У нас:

- **Энергия-поводок настроена**: тратится на действия, регенерируется сном/временем — но нет
  _причины вернуться через N часов_, кроме «накопил деньги». Банк офлайн-дней закрывает только часть.
- **Престиж-сток отсутствует**: нет ресета-«новой игры+» с мета-множителем и нет «статусного»
  стока (то, что в жанре платит деньгами). Это главная мета-дыра.
- **Поздний прогресс**: гейты карьеры требуют глубины навыков, но у «архитектора/CTO» почти нет
  целей → типичный спад дней 10–14.

### 1.3. Главные предложения по геймплею (детально в roadmap)

1. **Ежедневный стрик + награда за вход** (простая, огромный рычаг D1/D7).
2. **Мета-ресет «Новая жизнь» (престиж)**: после финала/CTO можно начать заново с бонусом
   (множитель XP, стартовый косметический скин «из прошлой жизни», особая рамка) — даёт
   бесконечную игру и долгий «сток».
3. **Сезоны/ивенты по времени** (неделя-месяц): офферы с таймером, «срочные» события.
4. **Коллекции-сеты в доме** («Полный ретро-уголок: +мотивация») — цель для магазина/дома.
5. **Архетипы-билды** в дереве навыков («Путь фронтендера»: JS→React→TS) с рамкой и бонусом —
   использует уже готовую галактику.
6. **События-офферы получают срок** (до конца дня/3 дня) — срочность.
7. **Мини-игра «собеседование» уже есть** → расширить: редкие «челленджи-вызовы» (типа
   хакатон-ивент) с наградой репутации.

## 2. UX/UI: что уже хорошо, что резать/переделывать

### 2.1. Что уже сделано (последние итерации)

- HUD: деньги — герой, репутация/рейтинг ушли в контекст, 3 метра-«ресурса решения».
- «День»: «Вчера» сворачивается, задание дня поднято, карточка карьеры — одна.
- Магазин: скан-строки, описания по тапу.
- Навыки: одна карта-«галактика» с зумом/панорамой, зоны школ, кистоуны, живые пути, мини-карта, фильтр школ.
- «Ещё» — список, таб-бар 4+«Ещё».

### 2.2. Болевые точки, которые остались

1. **Онбординг**: новый игрок получает сразу 4 категории × 5–7 действий, событие, подработки
   (после minDay) — когнитивная стена. Правило жанра: «первые 10 секунд — только клик и счётчик,
   сложность раскрывать постепенно».
2. **Магазин-монетизация спрятан** за «Ещё» (2 тапа) — по ресерчу IAP-витрина должна быть в 1 тап.
3. **Нет «карты целей»**: куда идти после «сделай 3 рабочих задачи» — непонятно; советы только
   текстом в карточке грейда.
4. **Длинные экраны без якорей**: SkillsView карта ок, но DayView всё ещё длинный (событие +
   советы + 4 сетки); подработки отдельной секцией — можно группировать «работа» вместе.
5. **Нет пустых/поощрительных состояний** в момент «энергия кончилась» — действия просто гаснут;
   не объясняется «поспи или заверши день».
6. **Доступность**: часть мелких текстов 9–10px, зоны тапа у некоторых чипов < 44px.
7. **Звук/вибрация**: только haptic; ок для ТГ, но можно «клик»-тик.
8. **Профиль игрока слабый**: «шар-карточка» есть, но нет страницы «я» (статистика, коллекции,
   кошелёк, спонсор-бейдж, настройки).

### 2.3. Полные переработки UX (shortlist)

- **A. Онбординг-«3 шага»** (выбор архетипа → первый день с 3 подсвеченными действиями → разблокировка
  остальных категорий по дням). Прогрессивное раскрытие в чистом виде.
- **B. «Мой профиль»** как отдельный экран (вместо «Топ»-соседа): статистика, коллекции, кошелёк.
- **C. Глобальный «командный пункт»**: верхняя строка целей («до Middle: React 30, English 15») —
  сейчас это в карточке карьеры только на «Дне».
- **D. Светлая тема?** — НЕТ (противоречит арту). Вместо неё: режим высокой контрастности.
- **E. Скриншот-шаринг с прогрессом** — есть ShareCard, доработать под NFT.

## 3. Код/архитектура: сильное и больное

### 3.1. Сильное

- Чистый движок в `packages/shared` (~6.6k строк, 66+ юнит-тестов), сервер-авторитет, клиент
  читает состояние; контент отдельно в JSON (схемы есть).
- Идемпотентность платежей (`entitlements.json` по charge_id), мок-режим для dev.
- NFT-провайдер и кошелёк-привязка уже заложены интерфейсом (`NftProvider`, `state.walletAddress`).
- UI-система документирована (`docs/ui.md`), палитра из спрайтов, пиксель-иконки.
- 65 тестов клиента, tsc/eslint чисто.

### 3.2. Больное (что переделывать)

1. **`routes/game.ts` = 1986 строк монолита** — действия, события, магазин, NFT, майнинг, собесы в одном
   файле. Переработка: разбить на action-хендлеры (по доменам) с общей валидацией/ответом.
2. **Хранилище** — JSON-файлы (`gameStore`, registry) вместо БД: ок для прототипа, но для
   лидерборда/аналитики/платежей нужен Postgres (или SQLite в один файл) + очередь.
3. **Нет телеметрии**: нечем мерить D1/D7, ARPPU, воронку. Для монетизации это блокер №1.
4. **Много `any` в клиенте/сервере**, дубли типов (Item, Player) между shared и views.
5. **Нет E2E** (есть smoke + vitest + tsx-прогоны) — перед «живыми деньгами» нужен Playwright-смоук
   покупки и 1 E2E-день.
6. **Клиент ~3k строк экранов** — растёт; пора вводить роутер-стек с back-навигацией получше
   (сейчас ручной `setView`/BackButton).
7. **Монорепо-скрипты**: нет единого `npm run dev:all` и docker-конфига для деплоя — для прод-пилота
   нужен деплой (Vercel/RAILWAY/Fly + Postgres).

## 4. Монетизация: Telegram Stars сегодня + Solana завтра

### 4.1. Что уже есть (задел)

- `content/monetization.json`: продукты за **Telegram Stars (XTR)** — «кофе разработчику» (донат),
  доп. день в банке, премиум-гардероб, неоновая комната. Политика: **только косметика, никакого pay-to-win**.
- `routes/payments.ts` + `StarsShop` в клиенте + idempotent-гранты.
- `NftProvider` (мок-реестр), привязка `walletAddress`, `mint/verify/collections/bonuses`.

### 4.2. Цифры ресерча (2025–2026)

- **Telegram Stars**: ~$0.02/star в приложении (Apple/Google −30%), ~$0.014–0.015 на Fragment.com;
  вывод: холд 21 день, мин. 1000 звёзд, конвертация через Fragment→GRAM→биржа. Для мелких
  импульсных покупок — идеально и «нативно» ([tribute.top/stars](https://tribute.top/blog/telegram-stars-creators-guide),
  [grambase](https://grambase.ai/blog/telegram-mini-apps-2026)).
- **Прямой крипто-платёж** (USDC на Solana): комиссия ~0–2.5% против ~30% у Stars → для крупных
  чеков и подписок выгоднее ([grambase](https://grambase.ai/blog/telegram-mini-apps-2026)).
- **Solana tx**: ~$0.00025; **cNFT (Metaplex Bubblegum/Compression)**: ~$0.000005–0.0001 за минт,
  1 млн ассетов ≈ $110–600 против $12k+ классических NFT; DAS API/Helius для чтения
  ([getmegabot](https://getmegabot.com/blog/solana-compressed-nfts-cnfts-complete-guide.html),
  [blueshift](https://learn.blueshift.gg/en/courses/nfts-on-solana/introduction),
  [merehead](https://merehead.com/blog/develop-nft-solana/)).
- **Кейсы ТГ+Solana**: PAWS (85M юзеров, 35M кошельков) ушёл с TON на Solana после политики
  Telegram «только TON»; ретейл-аудитория ТГ перетекает в Phantom ([bitget](https://www.bitget.com/news/detail/12560604634710),
  [beincrypto](https://beincrypto.com/telegram-mini-app-with-millions-of-users-migrate-to-solana/)).
- **Юридически/практически**: «играй-и-зарабатывай» токены с инфляцией чаще всего умирают;
  устойчивы **статус/престиж-стоки и собственность** ([dev.to economy sinks](https://dev.to/sam_novak_574b07811e18495/idle-game-economy-design-what-your-currency-sinks-actually-eat-1non)).

### 4.3. Стратегия: двухслойная монетизация

**Слой 1 — Telegram Stars (уже есть)**: мелкие импульсные покупки косметики, «кофе», доп.
дни. Не трогаем — это самый низкий фрикцион для casual-аудитории.

**Слой 2 — Solana как слой собственности и престижа** (не P2E-зарплата!):

1. **NFT-версии косметики** (уже купленной за Stars или заработанной): «выбить» предмет в cNFT
   себе в кошелёк — право показа в профиле, возможная перепродажа (роялти 5–10% автору).
   Платно: фикс. комиссия в SOL/USDC за минт (покрывает tree-ренту + маржу).
2. **Коллекционные дропы** (лимитированные серии по сезонам: «Лето в офисе» 500 шт.) — вечнозелёный
   повод возвращаться; редкие дают комнатные бонусы (косметические/малые).
3. **Премиум-подписка «Pro» за USDC/Stars**: + слоты банка, эксклюзив скины, аналитика прогресса,
   «без рекламы» (рекламы нет — вместо неё: ранний доступ к ивентам). Рекуррент — лучше через Stars
   (нативно) или USDC direct (дешевле).
4. **Реферальная программа** с токен-наградой за друзей (оффчейн-баллы → конвертация в предмет/cNFT),
   по образцу проверенных PAWS-механик, но без обещаний «заработать».
5. **Сезонный лидерборд**: топ-N сезона получают лимитированный cNFT-трофей — статус-сток, который
   в жанре платит деньгами (за бусты/повторы попыток — в Stars).

**Что НЕ делаем**: sell-силы/прогресса (нарушает policy и режет ретеншн), «играй-зарабатывай» с
обещанием денег (риск «мертвого токена» и регуляторики), азартные механики (лутбоксы с шансами
за деньги — вне рамок).

**Тех-стек для Solana-слоя** (план, фазы — см. roadmap):

- Кошелёк: Phantom через wallet-adapter/deeplink + Universal Link (без покидания ТГ — вебвью).
- Чтение владения: Helius DAS API (cNFT + обычные NFT одним запросом).
- Минт cNFT: Metaplex Bubblegum/Compressed (сервер кошельком-кастодианом или пользовательской
  подписью через `signAndSendTransaction`).
- Платежи: USDC SPL transfer с серверной сверкой (или Solana Pay link для веб-версии).
- Сверка/аудит: та же идемпотентная схема, что у Stars (charge_id → tx signature).

### 4.4. KPI перед запуском платных слоёв (блокер №1 — телеметрия)

D1/D7 retention, session length, ARPDAU, ARPPU, конверсия в Stars, % привязавших кошелёк,
стоимость минта cNFT/мес. Сейчас нечем мерить — см. roadmap P0 «телеметрия».

## 2. PR #10 — что реально внутри

3 коммита, 123 файла, +802/−41. База — ровно текущий main, ребейс не нужен.

### 2.1 Хорошая часть

- **Пайплайн существует и конечен**: `tools/art/avatar-key.mjs` (635 строк) —
  режимы `pupil / skinHair / hair / fullTop / fullBottom / item / anchor` с
  таблицей `OVERRIDES` под каждый мастер; `rebuild.sh` собирает всё за ~15 с.
- **Runtime лёгкий**: 38 webp 500×760, **312 КБ на всех** (1.7–12 КБ на слой),
  альфа есть у всех, размеры канваса соблюдены.
- **Контракт не сломан**: `id` записей манифеста в main и в PR #10
  **побайтово идентичны** — значит гардероб (`actions.ts:764`), NFT-синергии
  (`nftProvider.ts`) и кросс-валидация контента на переименования не нарвутся.
  Пути `/layers/avatar-v2/*.webp` совпадают с `buildLayerStack()`
  (он префиксует `/layers/${entry.file}`), `LayerManifestSchema` расширение
  файла не проверяет → валидация проходит.
- Клиент менять не надо: слоистый аватар уже примонтирован в `RoomRenderer`
  («Дом») и `OfficeRenderer` («Офис») — 7 слотов по `zOrder`.

### 2.2 Почему его нельзя влить как есть

**(а) 99 % объёма PR — не ассеты, а исходники.** Из 42.3 МБ добавленного
**41.9 МБ** — это `masters/` (PNG 0.7–1.1 МБ каждый: `t1/*`, `b2..b8/*`)
и отладочные рендеры `preview.png` (0.9 МБ) + `preview-all.png` (1.9 МБ).
Сами webp, которые идут в продакшн, — 312 КБ.

**(б) арт не откалиброван.** Я собрал композицию ровно так, как её соберёт
клиент (стек по `zOrder` без масштабирования), — см. вывод ниже:

- `body_base` — манекен с bbox **350×690**, при этом `top_hoodie_gray` —
  **245×245**, `top_shirt` — **235×284**. Одежда вырезана из _своих_
  фулл-фигурных мастеров и не совпадает с этим телом: белые руки и плечи
  манекена торчат из-за любого топа, ниже брюк видны белые ступни.
- Голова манекена ~90 px шириной, а `eye_normal` — **102 px**,
  `acc_glasses` — **128 px**: глаза и очки физически шире лица и вылезают
  за его контур.
- `hair_short` — **77×70** на канвасе 500×760 (`fill 0.6 %`),
  `hair_manbun`/`hair_undercut`/`hair_buzzcut` — и вовсе редкие дуги и точки.
  Волосы — это «чупа-чупс» на макушке, а не причёска: `anchor`-режим с
  `scale: 0.10–0.12` сжал крупно-плановые мастера до мускула.
- `beard_full` — bbox **y 136–230** при подбородке-лендмарке `chin: 168`,
  то есть борода висит на 60 px ниже лица, на воротнике.
- На правом плече топа виден белый осколок — остаток ключинга фона.

Грубая оценка: **12 слоёв из 38 годные** (7 топов + 5 низов — как картинки,
не как посадка), а весь «головной» набор (6 глаз, 10 причёсок, 4 бороды,
аксессуары на лице) и тело требуют переделки. То есть последний коммит
(«tune anchor placement + switch manifest to v2») — это середина настройки, а
не финиш.

**(в) тулинг непереносим.** В `rebuild.sh` первой строкой зашит абсолютный
путь песочницы агента:

```bash
cd /home/user/Itsim
```

На любой другой машине и в CI это падает сразу. Плюс `avatar-key.mjs`
резолвит `sharp`, только если запускать его из корня монорепо (sharp подтянут
хоистингом из `tools/isogen`), и нигде в `tools/art/package.json` не объявлен.

**(г) мёртвый код остаётся.** PR переключает манифест на webp, но не удаляет
старый SVG-слой `packages/client/public/layers/avatar/` (41 файл, 188 КБ).
После слияния он не ссылается ни на что (я прогрепал `packages/*/src` —
только упоминания в комментариях), то есть это осиротевший балласт.

**(д) ни тестов, ни docs.** Из `packages/` тронут ровно один JSON-манифест.
`docs/TODO.md`/`docs/DESIGN.md` описывают старый SVG-пайплайн с
грейскей-тинтингом, а про avatar-v2 не говорят ничего.

### 2.3 Что надо решить содержательно, прежде чем повторять

**Тинтинг убит.** В main у слотов `body/hair/beard` висит `tintSlot`, и
`layers.ts` красит грейскейл CSS-фильтром из генетики. PR #10 оставлял
`tintSlot` только у `body` (skinTone), а для волос/бороды удалил — «слои
предварительно окрашены». Цена: **цвет волос и бороды из генетики
(настройка seed'а) перестаёт влиять на аватар**; в UI эти опции остаются, но
становятся декоративными. Это надо или вернуть (маска/duotone-режим в
`avatar-key.mjs`), или осознанно вычистить trait'ы и UI — но не оставлять
как «само рассосётся».

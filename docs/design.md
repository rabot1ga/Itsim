## 1. Общая дизайн-система

**Формат:** Telegram Mini App, mobile-first, вертикальный экран (~390×844, iPhone-стиль).
Всё управление — одна рука, большие тач-зоны, нижняя навигация.

**Тема:** тёмная «ночной код».

| Элемент | Значение |
|---|---|
| Фон приложения | `#0b1220` + два радиальных свечения (голубое сверху, фиолетовое снизу) |
| Карточки (`.game-card`) | градиент slate-800→slate-900, скругление 16px, тонкая рамка, blur, тень |
| Акцент primary | sky/голубой `#0ea5e9` (кнопки, активные табы) |
| Второй акцент | violet/фиолетовый (градиенты CTA-кнопок) |
| Ресурсы | ⚡ энергия — indigo, ❤️ здоровье — emerald, 🔥 мотивация — amber, ⭐ репутация — violet, 💰 деньги — emerald |
| Грейды | каждый грейд свой цвет бейджа: стажёр cyan → junior emerald → middle sky → senior violet → teamlead amber → architect fuchsia → CTO rose |
| Шрифт | системный (SF/Roboto), цифры — `tabular-nums` + mono для денег |
| Эмодзи | основной «арт» интерфейса: иконки действий, навыков, наград (дешёво, читаемо, в духе Telegram) |

**Компоненты (переиспользуемые):**
- `.game-card` — карточка-секция; `.section-title` — заголовок с разделителем; `.chip` — маленький бейдж;
- `.btn-primary / .btn-secondary / .btn-success / .btn-danger` — кнопки;
- `ResourceChip` — ресурс с мини-прогрессбаром, пульсирует красным при < 25%;
- карточки списков: иконка слева → название + описание → цена/кнопка справа;
- тосты: красная карточка ошибки (закрывается тапом), янтарная карточка события.

## 4. Игровой каркас: верхняя панель и таббар

**ResourceBar** (`ResourceBar.tsx`) — закреплена сверху, видна на всех вкладках:
- Строка 1: слева «📅 День N», справа — 🏆 рейтинг и цветной бейдж грейда;
- Строка 2: 5 чипов — ⚡ энергия (значение/max + бар), ❤️ здоровье (бар), 🔥 мотивация (бар),
  ⭐ репутация (бар), 💰 деньги (текст, формат `1 млн ₽ / 25 тыс ₽`).
- Бары < 25% подсвечиваются красным и пульсируют — игрок сразу видит проблему.

**Нижний таббар** (`GameScreen.tsx`): 6 кнопок с иконкой + подписью 10px.
Активная подсвечена primary + подчёркнута полоской. Стили: blur-фон, safe-area отступ.

Файл `screens/SkillsView.tsx`. Дерево талантов **рендерится из контента** (`skills.json`) —

2. **9 веток** (каждая — свой цвет рамки): 🎨 Frontend · ⚙️ Backend · 📱 Mobile · 🔍 QA ·
   🐳 DevOps · 🤖 AI/ML · 🛡️ Кибербез · 🎮 GameDev · ⛓️ Blockchain;
3. Внутри ветки — навыки: эмодзи + название → уровень `N/max` + XP-бар до следующего уровня;
   заблокированные (по `parent`/`unlockAt`) — с 🔒 и условием;
4. **Выбор главного навыка** — звезда/кнопка «основной»: от него зависят вопросы собеса и доход;
5. **Софт-скиллы**: 🗣️ Коммуникация · 🇬🇧 Английский · 📊 Тайм-менеджмент · 👑 Лидерство ·
   🧘 Стрессоустойчивость · 🎤 Выступления — компактные бары;
6. **Перки** (8 шт): ⚔️ Фулстек · 🌅 Жаворонок · 📖 Скорочтение · 🗿 Стоик · 🤝 Нетворкер ·
   🎮 Про-геймер · 🪙 Золотая лихорадка · 🧳 Подработчик. У каждого — требования
   («JS 30 + Python 30») и эффект; доступный подсвечен кнопкой «Открыть», открытый — «✅».

## 8. Вкладка «🏠 Дом» — своя комната

Файл `screens/RoomView.tsx`. Самый «визуальный» экран игры. Сверху вниз:

### 8.1. Шапка
Заголовок «🏠 Дом» + справа моноширинный `seed a1b2c3d4…` (первые 8 символов генетического
сида игрока — его «родословная», см. DESIGN.md 3.1).

### 8.2. Рендер комнаты (`RoomRenderer.tsx`)
Квадрат 1:1, скругление 16px. Комната собирается из слоёв (см. §12), поверх —
**персонаж игрока** (слева внизу, ~1/3 ширины; сейчас пиксельный `PixelAvatar`,
fallback — слоистый SVG-аватар). В углу бейдж «жильё N/4».

Что видит игрок на картинке (слои сзади вперёд):
1. **Фон/стены** (`bg_0…bg_4`) — уровень жилья: общага → однушка → квартира в центре →
   ипотека → пентхаус; цвет стен затинтован генетикой (`wallColor` — у каждого свой оттенок);
2. **Окно** (`window_*`) — генетическая форма: квадратное / панорамное / круглое (rare) /
   арочное / жалюзи;
3. **Декор стены** (`decor_*`) — JS-постер / неон / серверная стойка (rare) / книги /
   доска / часы / Python-постер / легендарные Mad Lads и пиратский постер (cross-collection);
4. **Стол** (`desk_*`) — парта → IKEA → офисный → standing desk → RGB-стол (растёт с жильём);
5. **Атмосфера** (`atmo_*`) — растение / кактус / кофе / ковёр / лампа (опционально);
6. **Сетап** (`setup_*`) — ноутбук → монитор → dual → игровой ПК → MacBook → ultrawide
   (зависит от купленного ПК);
7. **Кресло** (`chair_*`) — табуретка → офисное → геймерское → Herman Miller → трон
   (зависит от купленного кресла);
8. **Питомец** (`pet_*`) — кот / корги / кактус / робот-пылесос / паук / бульдог в костюме,
   стоит/спит рядом (опционально, в будущем — 2-кадровая анимация idle/sleep);
9. **Персонаж** — поверх всего, «стоит» перед столом.

### 8.3. Панель идентичности (`PixelIdentity`)
«Паспорт» внешности: какие компоненты выбраны (лицо/глаза/рот/одежда/волосы/шапка/
аксессуар), что пришло из генетики (`trait`), а что из сида (`seed`), id цветовой схемы,
чексуммы контента (для воспроизводимости — см. pixel-art.md).

### 8.4. Ниже картинки — карточки
1. **👛 Кошелёк Solana**: адрес или поле ввода base58 + «Привязать». Подпись про генетику;
2. **🔗 NFT-предметы (мок)**: список заминченных покупок — название, трейты
   (`Slot:Chair · Rarity:Legendary…`), символ коллекции. Пусто — подсказка сходить в магазин;
3. **🌐 Cross-collection (мок-детект)**: SMB Gen2 / Mad Lads / DeGods — кнопки-переключатели
   «держу коллекцию» (в проде читается on-chain через Helius, сейчас мок). Влияют на декор
   и питомца в комнате + бонусы;
4. **📤 Шар-карточка** (`ShareCard.tsx`): превью Canvas-рендера (комната + статистика +
   рамка), кнопка «Поделиться» → PNG → Telegram шеринг. Драйвер виральности (K-фактор).

### 8.5. Редактор комнаты ✅ (реализован, см. §12.2)
Кнопка «🎨 Настроить комнату» под рендером → аккордеон со слотами → горизонтальные
карусели вариантов с мини-превью слоёв, замки 🔒 с подсказками «где взять»,
кнопка «✨ Авто» (возврат к автоматике) и перекраска стен (500 ₽).
Применение мгновенное (`customize_room`), превью обновляется из состояния игрока.
Без оверрайдов композиция собирается автоматически, как раньше.

## 11. Офис — как выглядит (проект)

> ✅ Реализовано: `screens/OfficeView.tsx` + `components/room/OfficeRenderer.tsx` +
> `content/layers/office_manifest.json` (11 слотов) + плейсхолдеры `public/layers/office/`
> (генератор `tools/generate_office_assets.py`). Офис = «вторая комната» на том же движке слоёв.

### 11.1. Где живёт
- Вход: карточка «🏢 Мой офис» вверху вкладки «Карьера» (видна, когда `employer != null`);
  тап → полноэкранный вид «Офис» (кнопка «← Назад в карьеру»).
- Безработный вместо офиса видит заглушку: пустой open-space с текстом
  «Сначала найди работу 💼» + кнопка к списку компаний.
- Тип офиса зависит от работодателя: 🚀 стартап = гараж/лофт, 📦 продукт = светлый open-space,
  🏢 корпорация = серые кубиклы, 🧩 аутсорс = коворкинг. Уровень — от размера/зарплаты компании.

### 11.2. Что видит пользователь (сверху вниз)
1. **Шапка**: «🏢 {Название компании}» + бейдж типа + день/неделя;
2. **Рендер офиса** (квадрат, как комната): слои сзади вперёд —
   фон open-space → панорамные окна с городом → доска задач/флипчарт → ряд столов команды →
   **твоё рабочее место** (стол + монитор с кодом + кресло по грейду: у стажёра табуретка
   у принтера, у CTO — кабинет со стеклянной стеной) → коллеги-NPC (2–4 фигурки за столами,
   берутся из `npcs.json`: ментор, токсик, HR, тимлид) → кофемашина/кулер → твой персонаж
   за своим столом;
3. **Состояние офиса** — бейдж поверх картинки, зависит от игрового контекста:
   ☀️ «Обычный день» / 🔥 «Дедлайн!» (красная подсветка, все NPC на месте) /
   🎉 «Пятница» (конфетти-слой, кулер с соком) / 🧘 «Ретро» / 🌙 «Ночной деплой»
   (тёмный фильтр, один монитор светится);
4. **Панель команды**: горизонтальный скролл чипов коллег — аватарка (пиксельная, по сиду NPC) +
   имя + отношение (💚/💛/❤️). Тап → попап: кто это, эффект («Ментор: +20% XP учёбы»),
   кнопка «Поговорить» (тратит энергию, качает отношения);
5. **Действия в офисе**: кнопки-действия дня, контекстные —
   💼 «Закрыть задачу» (основное), 🗣️ «Стендап» (малый бонус репутации, раз в день),
   ☕ «Кофе-брейк» (+мотивация, −время), 🌙 «Овертайм» (риск/награда), 💬 «1:1 с лидом»
   (открывает гейт повышения). Выполненные гаснут; всё то же API `performAction`, что и День;
6. **Прогресс до повышения**: мини-версия гейта («До Senior: навык 41/60, репутация 22/30»)
   + кнопка «Просить повышение» (появляется по `careerOutlook.canReview`).

### 11.3. Связь с механиками
- Офис — **скин над действиями**, а не отдельный симулятор: кнопки дергают те же ручки
  (`work_task`, `work_overtime`, `networking`), но с офисным оформлением и flavor-текстами;
- Вид рабочего места/кабинета растёт с грейдом (как `bg_N` комнаты растёт с жильём);
- Токсичность компании меняет палитру (серый фильтр + ☠️-декор) и пул событий;
- Ивенты офиса (code review, прод упал, корпоратив) показываются поверх рендера
  янтарной карточкой — как события Дня.

**Статус реализации:** рендер (11 слотов), муд-бейдж (эвристика: ночь при ⚡≤15%,
дедлайн при 🔥<30, пятница/ретро по дню недели), команда (3 NPC + отношения),
действия (задача/овертайм/стендап→нетворкинг), прогресс повышения через
`CareerPressureCard`, заглушка для безработных, вход из Карьеры, BackButton → в Карьеру.
Пока нет: персональных кнопок «Поговорить» у коллег (общий стендап),
«Кофе-брейка» и микрослотов своего стола за ачивки (авто-раскладка по грейду есть) —
следующая итерация.

## 12. Единая система индивидуальной кастомизации

Принцип: **«как персонаж — так и всё остальное»**. Персонаж уже собирается из слоёв
по сиду + манифестам + тинтингу. Та же тройка применяется к комнате, офису, питомцу
и всему новому. Один движок — много коллекций.

### 12.1. Как устроен персонаж сейчас (эталон)
1. **Генетика** (`shared/engine/genetics.ts` + `content/genetics.json`):
   `seed = sha256(wallet:game:base_genetics)` → детерминированные трейты
   (глаза, причёска, цвет волос/кожи/стен, окно, декор) с весами и редкостями;
2. **Пиксельный персонаж** (`docs/pixel-art.md`): канвас 32×32, категории
   `face → eyes → mouth → clothing → hair → hat → accessory`, 30 компонентов,
   цветовые схемы, `excludes`-правила, воспроизводимость `(seed, checksum…)`;
3. **Слоистый SVG-аватар** (`content/layers/avatar_manifest.json`): слоты
   `body / eyes(6) / hair(10) / beard(5) / top(7) / accessory(7)`, тинтинг волос/кожи;
4. **Рендер**: `buildLayerStack()` (сортировка по `zOrder` + CSS-тинт) и `renderPixelArt()`
   (canvas) — один код для игры, витрины и шар-карточки.

### 12.2. Комната по той же схеме (что есть → что добавить)

| Слот | Сейчас (авто) | Целевое (редактор) |
|---|---|---|
| 🖼 Обои/стены (`bg`) | `bg_0…4` по уровню жилья + тинт `wallColor` | + выбор текстуры из открытых (полоска, кирпич, граффити…) и цвета из палитры 12 шт |
| 🪟 Окно (`window`) | генетика, 5 форм | + шторы/жалюзи отдельным микрослоем, вид из окна (день/ночь/неон-сити) |
| 🖼 Декор (`decor`) | генетика/NFT, 9 шт | + 3 постер-слота с выбором + полка с наградами (ачивки материализуются!) |
| 🪑 Стол (`desk`) | по жилью, 5 шт | + выбор любого купленного, скины (RGB-подсветка вкл/выкл) |
| 🖥 Сетап (`setup`) | по купленному ПК, 6 шт | + обои монитора (мем/код/котик), 2-й монитор вертикально |
| 💺 Кресло (`chair`) | по покупке, 5 шт | + выбор любого купленного |
| 🪴 Атмосфера (`atmo`) | 6 шт | + свет-слой (тёплый/холодный/неон) и ковёр отдельно от лампы |
| 🐾 Питомец (`pet`) | по покупке, 7 шт | + скины и аксессуары (§12.4), позиция (у стола/на кресле) |
| 🆕 Пол (`floor`) | — | паркет/ламинат/ковёр во всю комнату, 6 шт |
| 🆕 Потолок (`ceiling`) | — | люстра/гирлянда/светодиодная лента, 6 шт (сезонные дропы!) |

**Откуда берутся варианты:** генетика (стартовый набор по сиду) · магазин (покупка
открывает слой навсегда) · ачивки (рамки, кубки на полку) · NFT/события (лимитки) ·
сезонные дропы (гирлянда, ёлка — FOMO/ретеншн).

**Редактор комнаты (UX) ✅ реализован:** кнопка «🎨 Настроить комнату» под рендером →
аккордеон слотов → горизонтальные карусели вариантов с мини-превью слоёв (тап = применить
сразу, без отдельной кнопки). Закрытые варианты — с 🔒 и подсказкой «где взять».
Смена бесплатна, если предмет открыт; перекраска стен — 500 ₽ («банка краски»);
плитка «✨ Авто» сбрасывает слот к автоматике.
Правила разблокировок — `shared/engine/roomDecor.ts` (единый код сервера и клиента),
экшен — `customize_room`, состояние — `player.room` (`RoomCustomization`).

### 12.3. Офис по той же схеме
Коллекция `office_manifest.json`: слоты `obg` (тип компании × уровень) / `ocity`
(вид из окна) / `oboard` (доска: kanban/схема/мотиватор) / `oteam` (расстановка столов) /
`odesk` (твоё место по грейду: табуретка → стол → кабинет) / `ocolleagues` (до 4 NPC-слотов) /
`ocoffee` (кулер/кофемашина/сок) / `omood` (оверлей состояния: дедлайн/пятница/ночь).
Кастомизация офиса беднее личной (это не твой дом): игрок меняет только своё место
(фото в рамке, фигурка, кружка — микрослоты за ачивки) и обои монитора.

### 12.4. Питомец по той же схеме
Коллекция `pet_manifest.json`: слоты `species` (6 видов + сезонные) / `skin` (окрасы,
тинтинг) / `wear` (ошейник RGB, худи, шляпа, галстук) / `state` (idle/sleep/happy —
2 кадра анимации). Кормёжка (`feed_pet`) переключает `state` на happy на день.
Легендарные скины — за кросс-коллекции (бульдог DeGods) и ачивки (кот в короне за CTO).

### 12.5. Всё остальное — тот же движок
- **Редактор персонажа**: генетика остаётся базой, но причёску/бороду/одежду/аксессуары
  можно менять в «🧍 Гардеробе» (подэкран Дома): стрижка 2 000 ₽, мерч — из магазина,
  медаль — за ачивку. Пиксельный и слоистый аватары меняются синхронно (один `combo`);
- **Шар-карточка**: темы рамок (`frame`: неон/золото/мем), выбираются за ачивки;
- **Меню/День**: сезонные фоны и иконки действий — тоже слои, включаемые флагом события.
- **Правило**: новая визуальная сущность = новый `*_manifest.json` + записи в контенте +
  серверная проверка владения. Код рендера (`buildLayerStack`, z-order, тинт, `excludeWith`)
  переиспользуется без изменений. Ассеты кладутся в `public/layers/<collection>/`,
  художник меняет файлы — код не трогаем (конвенция DESIGN.md §4).

## 16. Мобильная полировка под Telegram Mini App ✅ (реализовано)

Всё ниже уже в коде — это правила, которых придерживается клиент:

**Telegram API** (`lib/telegram.ts` — единая точка доступа, вне Telegram всё безопасно no-op):
- `initTelegramApp()`: `ready()` + `expand()`, тёмные `setHeaderColor/setBackgroundColor`,
  синхронизация `--tg-viewport-stable-height` по событию `viewportChanged`,
  `disableVerticalSwipes()` — свайп вниз не закрывает игру поверх скролла;
- **MainButton**: на вкладке «День» нативная нижняя кнопка «Завершить день N →»
  с прогрессом во время запроса; в браузере — sticky кнопка внутри скролла (`.sticky-cta`);
- **BackButton**: таб → вкладка «День» → меню → скрыта (можно закрыть);
- `index.html`: `viewport-fit=cover`, `user-scalable=no`, `theme-color #0b1220`.

**Хаптика** (везде через `haptic()`, типы — в `lib/telegram.ts`):
- табы/тогглы/выбор события — `selection`; обычные действия — лёгкий `tap`;
- покупки и завершение дня — `medium`; оффер/перк/верный ответ — `success`;
- ошибки — `error`; отказ на собесе — `warning`.

**Тач и вёрстка** (`index.css`):
- все кнопки ≥ 44pt (класс `.touch-target`, базовый `.btn` — тоже), иконки таба крупнее,
  `active:scale` как тактильный отклик;
- `touch-action: manipulation` (нет 300мс задержки), кнопки не выделяют текст,
  скролл `#game-scroll` с `overscroll-behavior: contain` (не дёргает Telegram);
- safe-area: `.safe-area-pt` у ResourceBar (чёлка), `.safe-area-pb` у таббара (home-индикатор);
- инпуты 16px — iOS не зумит при фокусе; у кошелька `enterKeyHint=done`, без автокорректа;
- контент ограничен 480px по центру — на десктопе «телефонная» рамка вместо растянутой простыни;
- `prefers-reduced-motion` отключает анимации.

**UX-мелочи**:
- после завершения дня скролл плавно едет наверх — к итогам и новому событию;
- ветки навыков — аккордеоны (открыты ветка основного навыка + прокачиваемые),
  основной навык закреплён плашкой «🎯 Основной» с переходом к ветке;
- кнопки ответов в квизе, выборы событий, «Купить»/«Откликнуться»/«Переехать» — крупные,
  во всю ширину там, где это главное действие.

## 17. Интерфейс (UI-система)

Персонаж рисуется в полный рост на холсте 500×760 (слоты `body → bottom → eyes
→ hair → beard → top → accessory`); пиксельный аватар 32×32 остался портретом
для карточки идентичности. Подробности — в [ui.md §8](ui.md).

Раздел вынесен в отдельный документ: **[ui.md](ui.md)** — палитра из спрайтов,
плоские поверхности, один золотой акцент, пиксельные иконки 12×12 вместо эмодзи
в хроме, компоненты `index.css`, чек-лист для нового экрана.

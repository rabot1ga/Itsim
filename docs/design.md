## 1. Общая рамка

**Формат:** Telegram Mini App, mobile-first, вертикальный экран (~390×844).
Одна рука, крупные тач-зоны, нижняя навигация, контент ограничен 480px по центру.

**Тема:** тёмная уютная. Фон `#0D1117`, карточки `#1B212C` с радиусом 16,
зелёный `#4ADE80` — действие и прогресс, золото `#F4D35E` — только деньги и
награды. Полная таблица токенов — в [design-system.md §1](design-system.md).

**Иконография:** эмодзи в хроме (заголовки, статы, чипы, плитки, меню),
пиксельные спрайты 12×12 — только в таббаре и внутри пиксель-арт-поверхностей.

## 2. Карта экранов и навигация

Файлы: каркас — `App.tsx`, `GameScreen.tsx`, `ResourceBar.tsx`; экраны —

## 3. Первый запуск

**Сплэш** (`App.tsx`): чёрный фон, слово «IT LIFE» и подпись — держится, пока
идёт `/state`.

**Онбординг** (`screens/OnboardingView.tsx`): 3 карточки со свайпом, точки-
индикаторы, «Пропустить» справа сверху, на последней — зелёная «Начать». Флаг
`itsim_onboarded_v1` в localStorage; сбрасывается из «Настроек».

Главного меню больше нет: игра открывается сразу на «Главной» — в мини-аппе
лишний экран между тапом по кнопке бота и игрой стоит дороже, чем даёт.

## 4. Каркас: топбар, HUD, таббар

`components/ResourceBar.tsx`:

1. **Топбар** — одна полоса 46px: деньги `1 250 ₽` табличными цифрами (и монеты
   мета-валюты, если есть), справа «День N» и кнопка «⋮». На под-экранах слева
   добавляется «‹», а перед днём — компактная ⚡. Заголовка приложения нет.
2. **HUD** (только на Главной) — одна карточка: портрет 60px, справа уровень

   (синяя), 😊 Настроение (оранжевое), ❤️ Здоровье (красное). Ниже 25% число
   краснеет — проблему видно, не читая цифр; точное «значение / max» — в
   тултипе.

`components/GameScreen.tsx` — контент + таббар 56px (5 вкладок) + шторка «Ещё»
на 10 строк (`.menu-row`: эмодзи → название → подсказка → шеврон).

## 6. Работа (`screens/CareerView.tsx`)

1. Текущая работа: компания, позиция, зарплата — или «Работы пока нет».
2. Быстрые действия рабочего дня (`.quick-actions`).
3. Проекты (`ProjectBoard`): активный проект с дедлайном и чек-листом задач,
   каталог доступных.
4. Карточка офиса → экран «Офис» (§11), если игрок трудоустроен.
5. `CareerPressureCard`: стоимость дня (сворачиваемая расшифровка) + прогресс к
   следующему грейду, выборы CTO, «Новая жизнь» после финала.
6. Офферы, отклик, квиз-собеседование (`InterviewPanel`), список компаний.
7. **«Повышение грейда · требования»** — вторичный сворачиваемый блок с гейтами
   из контента: навык, ветка, софт-скиллы, репутация, срок ревью.

## 7. Обучение (`screens/SkillsView.tsx` + `screens/SkillList.tsx`)

Дерево-карта заменено **плоским списком с аккордеоном по школам** — на 390px
карта читалась как домашка, список сканируется за секунду.

1. Карточка основного навыка: «Основной: Python», кнопка «Учиться».
2. Девять школ-аккордеонов (🎨 Frontend, ⚙️ Backend, 📱 Mobile, 🔍 QA, 🐳 DevOps,
   🤖 AI/ML, 🛡️ Кибербез, 🎮 GameDev, ⛓️ Blockchain), первая раскрыта. В шапке —
   «изучено / всего».
3. Строка навыка: двухбуквенный значок (или 🔒), название, «ур. N», метр
   прогресса до следующего уровня, `N / M XP`. Тап делает навык основным —
   выбранный обведён золотом и помечен «основной».
4. Заблокированный навык показывает точное условие: «Нужно: JavaScript: ур. 25
   (сейчас 12)».
5. Ниже — пути-архетипы (прогресс, «дальше: …», «Следовать»/«Забрать бонус»),
   мягкие навыки сеткой 3×N и перки с требованиями.

## 11. Офис

> ✅ Реализовано: `screens/OfficeView.tsx` + `components/room/OfficeRenderer.tsx` +
> `content/layers/office_manifest.json` (11 слотов) + плейсхолдеры `public/layers/office/`
> (генератор `tools/generate_office_assets.py`). Офис = «вторая комната» на том же движке слоёв.

### 11.1. Где живёт

- Вход: карточка «🏢 Мой офис» вверху вкладки «Карьера» (видна, когда `employer != null`);
  тап → полноэкранный вид «Офис» (кнопка «← Назад в карьеру»).
- Безработный вместо офиса видит заглушку: пустой open-space с текстом
  «Сначала найди работу 💼» + кнопка к списку компаний.
- Тип офиса зависит от работодателя: 🚀 стартап = гараж/лофт, 📦 продукт = светлый open-space,
  🏢 корпорация = серые кубиклы, 🧩 аутсорс = коворкинг. Уровень — от размера/зарплаты компании.

### 11.2. Что видит пользователь (сверху вниз)

1. **Шапка**: «🏢 {Название компании}» + бейдж типа + день/неделя;
2. **Рендер офиса** (квадрат, как комната): слои сзади вперёд —
   фон open-space → панорамные окна с городом → доска задач/флипчарт → ряд столов команды →
   **твоё рабочее место** (стол + монитор с кодом + кресло по грейду: у стажёра табуретка
   у принтера, у CTO — кабинет со стеклянной стеной) → коллеги-NPC (2–4 фигурки за столами,
   берутся из `npcs.json`: ментор, токсик, HR, тимлид) → кофемашина/кулер → твой персонаж
   за своим столом;
3. **Состояние офиса** — бейдж поверх картинки, зависит от игрового контекста:
   ☀️ «Обычный день» / 🔥 «Дедлайн!» (красная подсветка, все NPC на месте) /
   🎉 «Пятница» (конфетти-слой, кулер с соком) / 🧘 «Ретро» / 🌙 «Ночной деплой»
   (тёмный фильтр, один монитор светится);
4. **Панель команды**: горизонтальный скролл чипов коллег — аватарка (пиксельная, по сиду NPC) +
   имя + отношение (💚/💛/❤️). Тап → попап: кто это, эффект («Ментор: +20% XP учёбы»),
   кнопка «Поговорить» (тратит энергию, качает отношения);
5. **Действия в офисе**: кнопки-действия дня, контекстные —
   💼 «Закрыть задачу» (основное), 🗣️ «Стендап» (малый бонус репутации, раз в день),
   ☕ «Кофе-брейк» (+настроение, −время), 🌙 «Овертайм» (риск/награда), 💬 «1:1 с лидом»
   (открывает гейт повышения). Выполненные гаснут; всё то же API `performAction`, что и День;
6. **Прогресс до повышения**: мини-версия гейта («До Senior: навык 41/60, репутация 22/30»)
   - кнопка «Просить повышение» (появляется по `careerOutlook.canReview`).

### 11.3. Связь с механиками

- Офис — **скин над действиями**, а не отдельный симулятор: кнопки дергают те же ручки
  (`work_task`, `work_overtime`, `networking`), но с офисным оформлением и flavor-текстами;
- Вид рабочего места/кабинета растёт с грейдом (как `bg_N` комнаты растёт с жильём);
- Токсичность компании меняет палитру (серый фильтр + ☠️-декор) и пул событий;
- Ивенты офиса (code review, прод упал, корпоратив) показываются поверх рендера
  янтарной карточкой — как события Дня.

**Статус реализации:** рендер (11 слотов), муд-бейдж (эвристика: ночь при ⚡≤15%,
дедлайн при 🔥<30, пятница/ретро по дню недели), команда (3 NPC + отношения),
действия (задача/овертайм/стендап→нетворкинг), прогресс повышения через
`CareerPressureCard`, заглушка для безработных, вход из Карьеры, BackButton → в Карьеру.
Пока нет: персональных кнопок «Поговорить» у коллег (общий стендап),
«Кофе-брейка» и микрослотов своего стола за ачивки (авто-раскладка по грейду есть) —
следующая итерация.

## 12. Единая система индивидуальной кастомизации

Принцип: **«как персонаж — так и всё остальное»**. Персонаж уже собирается из слоёв
по сиду + манифестам + тинтингу. Та же тройка применяется к комнате, офису, питомцу
и всему новому. Один движок — много коллекций.

### 12.1. Как устроен персонаж сейчас (эталон)

1. **Генетика** (`shared/engine/genetics.ts` + `content/genetics.json`):
   `seed = sha256(wallet:game:base_genetics)` → детерминированные трейты
   (глаза, причёска, цвет волос/кожи/стен, окно, декор) с весами и редкостями;
2. **Пиксельный персонаж** (`docs/pixel-art.md`): канвас 32×32, категории
   `face → eyes → mouth → clothing → hair → hat → accessory`, 30 компонентов,
   цветовые схемы, `excludes`-правила, воспроизводимость `(seed, checksum…)`;
3. **Слоистый SVG-аватар** (`content/layers/avatar_manifest.json`): слоты
   `body / eyes(6) / hair(10) / beard(5) / top(7) / accessory(7)`, тинтинг волос/кожи;
4. **Рендер**: `buildLayerStack()` (сортировка по `zOrder` + CSS-тинт) и `renderPixelArt()`
   (canvas) — один код для игры, витрины и шар-карточки.

### 12.2. Комната по той же схеме (что есть → что добавить)

| Слот                   | Сейчас (авто)                               | Целевое (редактор)                                                                 |
| ---------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------- |
| 🖼 Обои/стены (`bg`)    | `bg_0…4` по уровню жилья + тинт `wallColor` | + выбор текстуры из открытых (полоска, кирпич, граффити…) и цвета из палитры 12 шт |
| 🪟 Окно (`window`)     | генетика, 5 форм                            | + шторы/жалюзи отдельным микрослоем, вид из окна (день/ночь/неон-сити)             |
| 🖼 Декор (`decor`)      | генетика/NFT, 9 шт                          | + 3 постер-слота с выбором + полка с наградами (ачивки материализуются!)           |
| 🪑 Стол (`desk`)       | по жилью, 5 шт                              | + выбор любого купленного, скины (RGB-подсветка вкл/выкл)                          |
| 🖥 Сетап (`setup`)      | по купленному ПК, 6 шт                      | + обои монитора (мем/код/котик), 2-й монитор вертикально                           |
| 💺 Кресло (`chair`)    | по покупке, 5 шт                            | + выбор любого купленного                                                          |
| 🪴 Атмосфера (`atmo`)  | 6 шт                                        | + свет-слой (тёплый/холодный/неон) и ковёр отдельно от лампы                       |
| 🐾 Питомец (`pet`)     | по покупке, 7 шт                            | + скины и аксессуары (§12.4), позиция (у стола/на кресле)                          |
| 🆕 Пол (`floor`)       | —                                           | паркет/ламинат/ковёр во всю комнату, 6 шт                                          |
| 🆕 Потолок (`ceiling`) | —                                           | люстра/гирлянда/светодиодная лента, 6 шт (сезонные дропы!)                         |

**Откуда берутся варианты:** генетика (стартовый набор по сиду) · магазин (покупка
открывает слой навсегда) · ачивки (рамки, кубки на полку) · NFT/события (лимитки) ·
сезонные дропы (гирлянда, ёлка — FOMO/ретеншн).

**Редактор комнаты (UX) ✅ реализован:** кнопка «🎨 Настроить комнату» под рендером →
аккордеон слотов → горизонтальные карусели вариантов с мини-превью слоёв (тап = применить
сразу, без отдельной кнопки). Закрытые варианты — с 🔒 и подсказкой «где взять».
Смена бесплатна, если предмет открыт; перекраска стен — 500 ₽ («банка краски»);
плитка «✨ Авто» сбрасывает слот к автоматике.
Правила разблокировок — `shared/engine/roomDecor.ts` (единый код сервера и клиента),
экшен — `customize_room`, состояние — `player.room` (`RoomCustomization`).

### 12.3. Офис по той же схеме

Коллекция `office_manifest.json`: слоты `obg` (тип компании × уровень) / `ocity`
(вид из окна) / `oboard` (доска: kanban/схема/мотиватор) / `oteam` (расстановка столов) /
`odesk` (твоё место по грейду: табуретка → стол → кабинет) / `ocolleagues` (до 4 NPC-слотов) /
`ocoffee` (кулер/кофемашина/сок) / `omood` (оверлей состояния: дедлайн/пятница/ночь).
Кастомизация офиса беднее личной (это не твой дом): игрок меняет только своё место
(фото в рамке, фигурка, кружка — микрослоты за ачивки) и обои монитора.

### 12.4. Питомец по той же схеме

Коллекция `pet_manifest.json`: слоты `species` (6 видов + сезонные) / `skin` (окрасы,
тинтинг) / `wear` (ошейник RGB, худи, шляпа, галстук) / `state` (idle/sleep/happy —
2 кадра анимации). Кормёжка (`feed_pet`) переключает `state` на happy на день.
Легендарные скины — за кросс-коллекции (бульдог DeGods) и ачивки (кот в короне за CTO).

### 12.5. Всё остальное — тот же движок

- **Редактор персонажа**: генетика остаётся базой, но причёску/бороду/одежду/аксессуары
  можно менять в «🧍 Гардеробе» (подэкран Дома): стрижка 2 000 ₽, мерч — из магазина,
  медаль — за ачивку. Пиксельный и слоистый аватары меняются синхронно (один `combo`);
- **Шар-карточка**: темы рамок (`frame`: неон/золото/мем), выбираются за ачивки;
- **Меню/День**: сезонные фоны и иконки действий — тоже слои, включаемые флагом события.
- **Правило**: новая визуальная сущность = новый `*_manifest.json` + записи в контенте +
  серверная проверка владения. Код рендера (`buildLayerStack`, z-order, тинт, `excludeWith`)
  переиспользуется без изменений. Ассеты кладутся в `public/layers/<collection>/`,
  художник меняет файлы — код не трогаем (конвенция DESIGN.md §4).

## 14. Состояния, обратная связь, мелочи

- **Загрузка**: комната — `RoomSkeleton`, списки — `Spinner`; контент не «прыгает».
- **Пустые состояния**: `EmptyState` с эмодзи, заголовком и подсказкой, что
  сделать («Загляни в магазин», «Откликнись на вакансии»).
- **Ошибки**: `role="alert"` + кнопка «Повторить»; серверный отказ никогда не
  выглядит как зависшая кнопка.
- **Недоступное**: `disabled` + причина текстом (энергия, деньги, навык).
- **Хаптика** через `haptic()`: `selection` — вкладки и выбор, `tap` — действия,
  `medium` — покупка и конец дня, `success` — оффер/ачивка, `error` — отказ.
- **Safe-area**: топбар и таббар учитывают вырезы; квадратные рендеры не
  перекрываются чёлкой.
- **Тон текстов**: самоирония айтишника, без токсичности; ошибка всегда
  подсказывает следующий шаг.

## 15. Мобильная полировка под Telegram Mini App

`lib/telegram.ts` — единственная точка доступа к WebApp API (вне Telegram — no-op):

- `initTelegramApp()`: `ready()` + `expand()`, тёмные `setHeaderColor` /
  `setBackgroundColor` (`#0d1117`), синхронизация `--tg-viewport-stable-height`,
  `disableVerticalSwipes()`;
- **MainButton** — «Завершить день N →» на «Главной», с прогрессом во время
  запроса; в браузере — sticky-кнопка внутри скролла;
- **BackButton** — под-экран → вкладка → скрыта;
- `openTelegramLink()` + `inviteLink()` — приглашение друзей;
- `openInvoice()` — оплата Telegram Stars.

Вёрстка: тач-таргет ≥ 44px, `touch-action: manipulation`, `overscroll-behavior`,
инпуты 16px (iOS не зумит), `prefers-reduced-motion` выключает анимации.

## 1. Реализовано в текущей ветке (v1.4)

### 1.1 Ядро

- [x] **Сервер-авторитет** (Fastify): 9 эндпоинтов в `/api/game` (state,
      action, advance-day, event-choice, perk, main-skill, interview×3,
      reset), плюс `sprint/claim`, `archetype/{choose,claim}`, `new-life`,
      11 в `/api/content`, 2 в `/api/leaderboard` (с пагинацией,
      «честной» доской и собственным рангом), payments/stars с боевым
      `createInvoiceLink` + проверенным вебхуком.
- [x] **JSON-персистентность** с атомарной записью и in-memory кэшем; версия
      2 с миграциями (`migrateState`) и защитой от сейвов «из будущего».
- [x] **Auth** через Telegram initData + HMAC + dev-фолбэк; rate-limit;
      идемпотентные ключи в самом сейве (64 ключа × 6 ч).
- [x] **Контент как данные** через `@itsim/content` (Zod-схемы 16 групп +
      cross-reference), CLI `validate:content` с `--strict` и `--json`.
- [x] **Безопасная конфигурация**: `config.ts` отказывает стартовать в
      production с dev-дефолтами (см. README §«Переменные окружения»).
- [x] **`routes/game.ts` разбит** на 11 модулей: `actions`, `day`,
      `shared`, `interview`, `misc`, `state`, `sprint`, `archetype`,
      `ending`, `_day` (helper), `index`. Самый большой — `actions.ts`
      (942 строки).

### 1.2 Игровые системы

- [x] 5 ресурсов (деньги, здоровье, мотивация, энергия, репутация),
      офлайн-банк дней (3.5 ч/день, кап 7), энергия как ресурс хода.
- [x] **Карьерные гейты** из контента + **ревью** + **конкуренция** за слот +
      **выборы CTO** (special-gate с `electionIntervalDays`).
- [x] **Стоимость жизни**: ежедневные расходы, режим «гречка», налог на
      капитал, переезды-подушки (`saveMult × saveStreakDays`), доходный
      барьер.
- [x] **205 событий** в 19 файлах: цепочки, кулдауны, теги, NPC-условия,
      follow-up'ы на действия.
- [x] **34 навыка / 9 веток**, основной навык, 8 перков, мягкие навыки с
      насыщением, английский.
- [x] **Квиз собеседований**: 56 вопросов по 14 веткам × 3 уровня, topic-first
      раздача, XP за ответ, `answerScore` подмешивается в шанс оффера.
- [x] **10 компаний** с культурами-модификаторами и требованиями к
      английскому, офферы со сгоранием, отклики, увольнения, 5 NPC.
- [x] **Фриланс**, 7 подработок, **майнинг-ферма** (оборудование,
      электричество, солнечные панели, детерминированная волатильность).
- [x] **17 ачивок**, 13 daily-челленджей, 3 сезонных спринта, живой
      лидерборд.
- [x] **Питомцы 2.0**: 9 видов (cat/dog/cactus/robo/spider/bulldog/parrot/
      hamster/fish), кормление, настроение, 3 аксессуара.
- [x] **Мета-ресет «Новая жизнь»**: `player.meta` (жизни, воспоминания,
      лучший грейд, `metaXpMult` +15% за жизнь до +75%).
- [x] **Спринты + архетипы** (3 сезонных темы, выбор архетипа в начале
      спринта, накопительный claim).
- [x] **6 финалов** в `balance.endings` (cto/exit/free_artist/teacher/
      burnout/left_it), экран `EndingView` и экшен `claim_ending`.

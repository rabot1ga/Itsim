# UI: карточная система (P0.7)

Документ описывает **карточный слой интерфейса** — то, как мини-апп выглядит после
редизайна P0.7. Он заменяет «плоские пиксельные плашки с 9-slice PNG» из старой
версии [ui.md](ui.md) как описание хрома; [design.md](design.md) (что рисуем:
комнаты, персонажи, офис) и [pixel-art.md](pixel-art.md) (как рисуем спрайты)
продолжают действовать без изменений.

Референсы редизайна — `docs/design-references/reference-1.png` и
`reference-2.png` (тёмная база, палитра игры, крупные спрайтовые объекты).

## Идея

Мир игры — пиксельный (персонажи, комнаты, офис, животные, изометрия) и остаётся
таким: спрайты и пиксельные иконки не перерисовываются, `image-rendering:
pixelated` никто не отключает. Меняется только **рама вокруг картинки**:

- интерфейс — мягкие карточки: скруглённые поверхности, слоистые тени,
  волосяная рамка с подсвеченной верхней кромкой;
- пиксельная «начинка» (ноды карты навыков, спрайты, эмодзи-токены) живёт
  **внутри** мягких плашек-«сокетов», оставаясь crisp;
- вся геометрия — в CSS-токенах `--radius-*` / `--shadow-*`, поэтому общий вид
  меняется в одном месте;
- семантика цветов и «один золотой акцент» сохранены из старой системы.

## 1. Токены (`packages/client/src/index.css`, `:root`)

### Поверхности и геометрия

| Токен                     | Значение | Роль                                     |
| ------------------------- | -------- | ---------------------------------------- |
| `--radius-card`           | `18px`   | панели, карточки                         |
| `--radius-tile`           | `14px`   | кликабельные плитки (действия)           |
| `--radius-control`        | `12px`   | кнопки                                   |
| `--radius-well`           | `10px`   | вложенные «сокеты», плашки иконок        |
| `--radius-chip`           | `999px`  | чипы, пилюли, метры                      |
| `--tap`                   | `44px`   | минимальная тач-зона                     |
| `--shadow-card`           | см. CSS  | тень карточки + верхний блик             |
| `--glow-gold/-moss/-clay` | см. CSS  | мягкое свечение CTA / успеха / опасности |

Тона для карточек событий заданы RGB-триплетами (`--tone-gold: 244 211 94`, …),
чтобы один цвет можно было использовать с разной прозрачностью:
`rgba(var(--tone-gold) / 0.12)`.

### Класс-основа

```css
.card-surface {
  /* градиент поверхности + рамка 1px + --shadow-card */
}
```

Каждая поверхность = тёмный градиент `#242d3d → #171e2a` с едва заметным
верхним бликом; волосяная рамка `1px var(--line-strong)`.

## 2. Примитивы (имена классов не менялись)

Старые имена остались — поменялась их реализация (вместо `border-image`
9-slice PNG — CSS-поверхности). Поэтому все экраны обновились автоматически.

| Класс                                                   | Теперь                                                                                   |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `.panel` / `.game-card`                                 | карточка `--radius-card`, градиент, `--shadow-card`                                      |
| `.tile`                                                 | плитка `--radius-tile`; hover — светлее рамка, press — утоплена на 1px и «тёплая» (gold) |
| `.well`                                                 | вдавленный сокет `--radius-well` (inset-тень)                                            |
| `.plate`                                                | новый: плашка-«сокет» под арт/иконку                                                     |
| `.panel-note[-gold\|-sky\|-moss\|-clay\|-ochre]`        | цветной «позвоночник» 3px слева внутри скруглённой карточки                              |
| `.btn[-primary\|-secondary\|-ghost\|-success\|-danger]` | мягкие клавиши `--radius-control`; primary — золотой градиент со свечением               |
| `.btn-lg`                                               | 56px, чуть больший радиус                                                                |
| `.chip` / `.stat-pill`                                  | пилюли `--radius-chip`                                                                   |
| `.meter`                                                | «батарейка» 6px, скруглённая, без ступенчатой маски                                      |
| `.tabbar-item[data-active]`                             | золотая капсула с мягкой заливкой                                                        |
| `.divider`, `.section-title::after`, `.eyebrow::after`  | затухающий градиент-волосок вместо пиксельного пунктира                                  |
| `.gain-float`                                           | капсула со свечением вместо жёсткой рамки                                                |

`.animate-float`/`.animate-gradient` по-прежнему no-op; всё движение осталось
коротким и отключается при `prefers-reduced-motion`.

9-slice PNG (`public/ui/*`) больше не потребляются CSS-примитивами и остались
только как артефакты для будущих пиксельных вставок; генератор
`tools/uigen` не удаляем.

## 3. Карточка случайного события (`EventCard`, `screens/DayView.tsx`)

Случайное событие — «карточка дня» в стиле референсов. Анатомия сверху вниз:

1. **Медленный цвет** — тон карточки определяется тегом события
   (`.tone-*`, едва заметная заливка угла + полоса под шапкой + цвет иконки).
2. **Шапка**: медальон-«сокет» 44×44 с ведущим эмодзи заголовка события
   (или тематической пиксельной иконкой), каппер-категория и заголовок.
3. **История** — описание события.
4. **Выборы** — приподнятые строки-кнопки с чипами ресурсов (`ev-chip`):
   `−500 ₽`, `+2 ⚡`, `★+1`, `📚 +N XP` — цвета строго по знаку
   (moss = плюс, clay = минус), числа не угадываются, а читаются из
   `effects` контента (все 583 выбора в контенте содержат полные effects).

Мэппинг тон → категория (`EVENT_TONES` в DayView): кризис/toxic → clay
«Кризис»; reward → gold «Награда»; работа/карьера/tech → gold «Работа»;
учёба/школы → sky «Учёба»; деньги/крипта/майнинг → moss «Деньги»;
люди/семья/питомцы → sky «Люди»; здоровье → moss «Здоровье»;
chain → sky «История»; по умолчанию ochre «Событие».

## 4. Пиксельный мир внутри карточек

- `SpriteBadge`/`EmojiToken` (components/ui.tsx) — «сокеты» `--radius-well` с
  inset-тенью; сам спрайт/эмодзи не скругляется и не размывается.
- Ноды карты навыков и их рамки — **часть мира**: остаются пиксельными;
  скруглён только контейнер-«витрина» карты, чипы фильтров школ стали
  пилюлями, легенда — скруглёнными квадратами.
- Правило: UI-хром мягкий, мир квадратный. Если элемент рисует игровой объект
  (нода, спрайт, комната) — он пиксельный; если элемент управляет игрой
  (кнопка, панель, чип) — он карточка.

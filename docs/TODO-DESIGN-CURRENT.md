## Критерий готовности

Не «тесты зелёные», а одновременно: совпадает композиция референса, сцена
соответствует теме, нет встроенных в картинки кнопок/цен, данные настоящие,
понятны последствия каждого решения, нет переполнения 320/390/480 px.
Новое AI-generated изображение не означает юридическую гарантию уникальности;
происхождение фиксируем явно, перед публикацией нужен обычный review ассетов.

## UI 09 — проекты с дедлайнами (экран «Работа» из 1.png)

Референс показывает на экране «Работа» контракт с дедлайном, полосу прогресса,
чек-лист задач и список заказов с оплатой. Раньше этого в игре не было — были
только мгновенные действия. Теперь это настоящая механика, а не картинка:

- `packages/content/projects.json` — 5 проектов, каждый с задачами, оплатой,
  сроком и порогом по основному навыку. Валидатор контента проверяет уникальные
  id, уникальные задачи и что дедлайн не короче числа задач.
- `packages/shared/src/engine/projects.ts` — чистый движок: прогресс, дни до
  срока, причина блокировки, выплата и штраф. День дедлайна ещё считается
  сроком; сдача позже платит 60% и не даёт репутации.
- Сервер: действия `take_project`, `project_task`, `deliver_project`,
  `drop_project`; энергия задачи берётся из её описания. Просроченный проект
  закрывается при смене дня и снимает репутацию.
- Клиент: `ProjectBoard` на экране «Работа» — активный контракт с процентом и
  дедлайном, чек-лист, кнопки сдачи и отказа, список доступных заказов с
  честной причиной блокировки. Быстрые действия переехали ниже.
- Тесты: 6 модульных на движок + 3 E2E через реальный сервер (полный цикл со
  сдачей, пропущенный дедлайн со штрафом, отказ). E2E сбрасывают жизнь до и
  после себя, чтобы не тратить дни соседних сценариев.

Итог проверки UI 09: `npm test` — 354 теста пакетов (186 shared + 51 server +
22 pixelgen + 95 client), валидация контента и симуляция успешны, общий lint
чистый, **25 E2E прошли**.

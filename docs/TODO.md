# IT Life Simulator — актуальный To-Do

Этот документ — **живая правда** о том, что в проекте реализовано, что в
процессе и что предстоит. Дизайн описан в
[design-system.md](design-system.md) и [design.md](design.md).

Версии в коде: `@itsim/shared` 2.0.0, `balance.json` v2.1.0.

---

## 1. Реализовано

### 1.1 Ядро

- [x] **Сервер-авторитет** (Fastify): 9 эндпоинтов в `/api/game` (state,
      action, advance-day, event-choice, perk, main-skill, interview×3,
      reset), плюс `sprint/claim`, `archetype/{choose,claim}`, `new-life`,
      11 в `/api/content`, 2 в `/api/leaderboard` (с пагинацией,
      «честной» доской и собственным рангом), payments/stars с боевым
      `createInvoiceLink` + проверенным вебхуком.
- [x] **JSON-персистентность** с атомарной записью и in-memory кэшем; версия
      3 с миграциями (`migrateState`) и защитой от сейвов «из будущего».
- [x] **Auth** через Telegram initData + HMAC + dev-фолбэк; rate-limit;
      идемпотентные ключи в самом сейве (64 ключа × 6 ч).
- [x] **Контент как данные** через `@itsim/content` (Zod-схемы 16 групп +
      cross-reference), CLI `validate:content` с `--strict` и `--json`.
- [x] **Безопасная конфигурация**: `config.ts` отказывает стартовать в
      production с dev-дефолтами (см. README §«Переменные окружения»).
- [x] **`routes/game.ts` разбит** на 11 модулей: `actions`, `day`,
      `shared`, `interview`, `misc`, `state`, `sprint`, `archetype`,
      `ending`, `_day` (helper), `index`. Самый большой — `actions.ts`
      (942 строки).

### 1.2 Игровые системы

- [x] 5 ресурсов (деньги, здоровье, мотивация, энергия, репутация),
      офлайн-банк дней (3.5 ч/день, кап 7), энергия как ресурс хода.
- [x] **Карьерные гейты** из контента + **ревью** + **конкуренция** за слот +
      **выборы CTO** (special-gate с `electionIntervalDays`).
- [x] **Стоимость жизни**: ежедневные расходы, режим «гречка», налог на
      капитал, переезды-подушки (`saveMult × saveStreakDays`), доходный
      барьер.
- [x] **205 событий** в 19 файлах: цепочки, кулдауны, теги, NPC-условия,
      follow-up'ы на действия.
- [x] **34 навыка / 9 веток**, основной навык, 8 перков, мягкие навыки с
      насыщением, английский.
- [x] **Квиз собеседований**: 56 вопросов по 14 веткам × 3 уровня, topic-first
      раздача, XP за ответ, `answerScore` подмешивается в шанс оффера.
- [x] **10 компаний** с культурами-модификаторами и требованиями к
      английскому, офферы со сгоранием, отклики, увольнения, 5 NPC.
- [x] **Фриланс как отклик на бирже заказов** (`freelance` +
      `params.projectId`, −3 ⚡, один в день): заказчик отвечает утром —
      контракт, оплаченное тестовое или отказ; кнопки «Взять» на доске
      больше нет. 7 подработок, **майнинг-ферма** (оборудование,
      электричество, солнечные панели, детерминированная волатильность).
- [x] **17 ачивок**, 13 daily-челленджей, 3 сезонных спринта, живой
      лидерборд.
- [x] **Питомцы 2.0**: 9 видов (cat/dog/cactus/robo/spider/bulldog/parrot/
      hamster/fish), кормление, настроение, 3 аксессуара.
- [x] **Мета-ресет «Новая жизнь»**: `player.meta` (жизни, воспоминания,
      лучший грейд, `metaXpMult` +15% за жизнь до +75%).
- [x] **Спринты + архетипы** (3 сезонных темы, выбор архетипа в начале
      спринта, накопительный claim).
- [x] **6 финалов** в `balance.endings` (cto/exit/free_artist/teacher/
      burnout/left_it), экран `EndingView` и экшен `claim_ending`.

## 3. Что изменил редизайн (для ревью)

- Навигация: 5 вкладок + «⋮» вместо 7 табов; пятую вкладку занял «Отдых»,
  «Друзья» переехали в «⋮».
- «⋮» стала сеткой-индексом 3×N, а её разделы получили контекстные двери
  (`components/NavLinks.tsx`): офис/финалы/топ на «Работе», майнинг и кошелёк
  в «Магазине», дом и питомец на «Отдыхе», цели и топ в «Профиле».
- Действия ушли с Главной по своим вкладкам; каталог один
  (`screens/actionCatalogue.ts`), вид плитки один (`ActionGrid`).
- Обучение разделено переключателем «Действия» / «Направления».
- Обучение: список-аккордеон вместо радиальной карты
  (`skillTreeLayout.ts` и его тест удалены).
- Хром: `.reference-*` / `.panel` / `.game-card` заменены на `.card` и
  соседей; `PixelIcon` остался только в таббаре.
- «Мотивация» переименована в «Настроение» во всём клиентском тексте
  (поле состояния `motivation` на сервере не тронуто).
- Новые экраны: «Настройки» и онбординг.
- Документация: `ui.md`, `ui-card-system.md`, `ui-research.md`,
  `TODO-DESIGN-CURRENT.md`, `TODO-2026-09-08-integration.md`,
  `roadmap-2026-09-08.md`, `product-audit-2026-09-08.md` удалены как
  устаревшие; их актуальная часть переехала в `design-system.md`.

## 4. Ближний план

### P2.1 HUD-«Кошелёк» (планируется)

Быстрый доступ к NFT-инвентарю из верхней панели (сейчас — только через
«⋮» → Кошелёк). Бейдж с количеством новых покупок.

### P2.2 Реальный Solana-провайдер (Helius RPC)

Интерфейс `NftProvider` уже узкий, мок-реестр в `data/nft_registry.json`.
Замена без переделки роутов.

### P2.3 Контент-наполнение поздней игры

Эндгейм (architect+) сейчас трудный, но пустой: финалы достижимы, но
после CTO нет ни контента, ни механик. Добавить события/проекты/новые
покупаемые бейджи.

### P2.4 Серверный RNG везде, где влияет на баланс

Сейчас серверный — только вопросы квиза и генетика; события всё ещё
используют клиентский seed. Нужен миграционный план.

### P2.5 i18n (EN)

Тексты в коде, не вынесены; нужна инфраструктура словарей.

### P2.6 PostgreSQL + Prisma

JSON-персистентность работает, но миграции сейвов и интерфейс хранилища
уже узкие — переезд не сломает вызовы.

### P2.7 `npm run format` по всей базе

Сейчас в CI `continue-on-error`, чтобы не смешивать с содержательными
правками; нужно отдельное окно.

## 5. Не входит в ближний план

- **Звуки** и **режим высокого контраста** (до i18n).
- **Анимации питомца** idle/sleep/happy (сейчас — CSS-покачивание + эмодзи).
- **Рукотворные арты** вместо плейсхолдеров генераторов (ассет-лист — в
  DESIGN.md, ~170 шт).

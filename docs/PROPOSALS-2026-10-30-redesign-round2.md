## A. «Династия» — жизнь как забег, смерть как глава

**Суть:** жизнь = роглайт-забег (несколько недель игрового времени, 30–60 минут
игры), смерть/финал — не «game over», а глава семейной саги. Игрок продолжает
за наследника; мета-прогресс живёт в «древе крови».

- **UX/UI:** колода — как есть, но стек дня получает «эпоху» (главу жизни).
  Главный новый экран — **«Эпитафия»**: красивая шаринг-карточка жизни
  (заголовок, тайм-лайн, 3 главных факта) с кнопкой «Отправить в чат» —
  вирусный момент прямо в Telegram. Дерево крови — вертикальная лента предков
  с чертами/наследием.
- **Core loop:** жизнь → финал → эпитафия (шаринг) → выбор наследника →
  новая жизнь с бонусами крови. «Ещё одна жизнь» — главный ритм.
- **Механики-дельты:** генетика/черты наследуются (сейчас архетипы — один шаг
  до этого); очки наследия тратятся в древе крови (мета-прогресс); рекорды
  семьи; короткие «судьбоносные» жизни (опция).
- **Что с «Колодой»:** сохраняется полностью — колода живёт внутри эпохи.
- **Судьба A–I:** финалы B1–B6 становятся «главами»; ачивки → семейные реликвии.
- **Объём:** клиент ≈2–3 сессии (эпитафия + древо), сервер: наследование +
  пересчёт мета (≈1–2 сессии). **Риск:** баланс «одна жизнь» vs долгая карьера.

**Почему сейчас:** поколенческие симы (Genworld, Sentience с династиями и
генетикой) — самый горячий тренд лайф-симов; роглайт-мета («проигранный забег
всё равно даёт прогресс») — проверенный удержатель; шаринг эпитафий =
органический рост в Telegram.

## B. «Живой мир» — память, соперники, общая история

**Суть:** мир **помнит игрока**. Каждое решение оставляет след: компании
помнят твои отклики, коллеги — твои слова, соперник растёт вместе с тобой.
События генерируются из прошлого, а не из случайного списка.

- **UX/UI:** «Хроника» — фид-дневник (не газета раунда A1, а лента «что мир
  про тебя помнит»): карточки NPC с общей историей («вы вместе работали в
  Portal-2000»), карточка соперника («Марина тоже претендуеет на повышение»),
  бейджи репутации в компаниях/кварталах.
- **Core loop:** действие → след в мире → след возвращается событием
  (благодарность, месть, слух) → новые следы.
- **Механики-дельты:** система памяти NPC (у нас уже есть `mem:`-вехи —
  расширяем до диспозиций); соперник за повышение (уже есть `competition` в
  careerGates — выводим в персонажа); репутация компаний; цепочки событий из
  прошлых решений (235 событий получают «сиквелы»).
- **Что с «Колодой»:** сохраняется; карточки событий получают блок «Тебя
  помнят…».
- **Судьба A–I:** memory-milestones → ядро; крючки G → «слухи о тебе».
- **Объём:** сервер ≈2–3 сессии (диспозиции, сиквелы), клиент ≈2 (хроника,
  NPC-карточки). **Риск:** сложность тьюнинга — «мир злится» не должен бесить.

**Почему сейчас:** главная претензия к лайф-симам 2026 — «NPC забывают тебя»;
игры с адаптивной памятью заявляют +43% D30-ретеншена; «магазин помнит твою
кражу» — то, чем хвалятся новые инди-симы.

## C. «Команда» — играть одному можно, но скучно

**Суть:** Telegram-native социальный слой: сквад друзей, асинхронные
«призраки» друг друга, совместные сезонные цели. Одиночная игра остаётся,
но каждый акт становится видимым/полезным команде.

- **UX/UI:** в стеке дня появляются **карточки друзей** («Аня завершила
  спринт — поздравь» / «Дима ищет, кого позвать на хакатон»); «Комната
  команды» — общая панель с аватарками, общим прогрессом-баром недели и
  лентой достижений. Приглашение друга — карточка-предложение прямо в чат.
- **Core loop:** личное действие → видимый след в команде → реакция друга
  (энергия/поздравление) → общий результат недели → награда всем.
- **Механики-дельты:** сквад до N человек; сквад-спринт (общая цель недели —
  у нас уже есть SprintCard!); «письма поддержки» = +энергия от друга;
  сезонный кубок сквадов; реферальные ачивки.
- **Что с «Колодой»:** сохраняется; слот `friends` в стеке 2–3 раза в неделю.
- **Судьба A–I:** рейтинг/лидерборды → кубок сквадов; челленджи → общие.
- **Объём:** сервер ≈2–3 сессии (сквады, синхронизация), клиент ≈2. **Риск:**
  сетевые состояния (пустые сквады, мёртвые друзья) — нужен честный офлайн.

**Почему сейчас:** лидерборды дают +25% ретеншена (Newzoo); асинхронный социал
— тренд №1 в казуале; Telegram даёт граф друзей бесплатно; Hamster Kombat
показал: вирусность без удержания пуста — социал и есть удержание.

## D. «Тихая гавань» — cozy-ревизия, комната как интерфейс

**Суть:** максимальный поворот к cozy/wellness: меньше давления, больше
уюта. Интерфейс живёт **в комнате** (diegetic UI): тап по объектам —
действия, никаких меню-списков. Числа прячутся, формулировки мягкие.

- **UX/UI:** одна сцена-комната, которая **визуально растёт** с прогрессом
  (появляется техника, растения, питомец, свет); действия — тап по объектам
  (клавиатура = работа, кружка = кофе, диван = отдых); колода остаётся для
  событий-решений. Свет/звук по времени суток (утро/вечер), ambient-звук.
  HUD сжимается до одной строки-«настроения».
- **Core loop:** ритуал дня (устроиться поудобнее) → 3–5 тапов по комнате →
  вечерний уют → комната красивее.
- **Механики-дельты:** «энергия» → «ритм» (мягкие провалы: «сегодня не
  сложилось» без штрафов-чисел); декор комнаты = видимый прогресс (шкала
  скиллов уходит в «полки с книгами/грамотами»); wellness-напоминания
  (перерыв = механика).
- **Что с «Колодой»:** колода = события и сюжет; рутина уходит в комнату.
- **Судьба A–I:** HomeRoomCard (уже есть!) — ядро этого варианта; питомец —
  главный «житель» комнаты.
- **Объём:** клиент ≈3 сессии (сцена комнаты, объекты), сервер ≈1 (мягкая
  экономика). **Риск:** поклонники цифр/оптимизации (из аудита: «оптимизация
  вместо симулятора» — антипаттерн) могут соскучиться по жёсткости.

**Почему сейчас:** cozy-волна — самый быстрорастущий сегмент (Newzoo,
GameRefinery); diegetic UI — тренд 2026 в фармингах/лайф-симах; у нас уже
есть комната с питомцем и тирами — почти готовая сцена.

## E. «Сезоны» — жизнь как шоу с еженедельным выпуском

**Суть:** live-ops модель: каждую неделю — новый «сезон» с темой, событийными
карточками и треком наград. Неделя перестаёт быть календарной — становится
**шоу-эпизодом** с завязкой, кульминацией и итогом.

- **UX/UI:** «Карта сезона» — вертикальный трек с наградами (мета-прогресс:
  косметика комнаты, перки-модификаторы, титулы); тематические оформления
  колоды (неделя хакатона = неон, неделя отпуска = пляж); событийные карточки
  с уникальными модификаторами (мы уже построили систему модификаторов!).
- **Core loop:** понедельник = анонс сезона (стартовая карточка) → события
  недели с модификаторами → суббота = «выпуск» с итогами → награды трека →
  следующий сезон.
- **Механики-дельты:** сезонный трек (очки недели → награды мета); глобальные
  цели комьюнити («все игроки закрыли 100k задач»); ротация контента-модификаторов
  (карточка работы каждую неделю играет иначе); «редактор недели» — карточка
  с настроем/правилами недели (×2 XP, но −настроение).
- **Что с «Колодой»:** сохраняется и усиливается — модификаторы карт уже
  готовы (стадия 3), остаётся добавить сезонный слой.
- **Судьба A–I:** спринт-темы (уже есть `sprints.json`) → серия сезонов;
  чек-листы → «цели выпуска».
- **Объём:** клиент ≈2 (карта сезона, темы), сервер ≈2 (трек, очки, ротации).
  **Риск:** контентная нагрузка — сезон без наполнения = «пустой батлпасс»
  (главный анти-паттерн LiveOps).

**Почему сейчас:** гибрид-казуал 2026 = простой цикл + мета-петли + лайв-ивенты;
сезонные треки, платящие в мета-прогресс, — лучшая практика удержания;
у нас уже «сезон недели» — этот вариант доводит его до логического конца.

## Что говорят источники (октябрь 2026)

- Гибрид-казуал — новый дефолт: простой цикл + глубокие мета-петли; ретеншен
  держат мета-системы, а не ядро (r/AppFollow «Mobile Gaming Trends 2026»;
  Medium «Top Trends in Mobile Game Development»).
- Cozy/wellness — растущий сегмент; diegetic UI (ящик = квест-центр) и
  вертикальный one-handed дизайн — тренды лайф-симов (GameRefinery/Newzoo).
- ИИ-нарратив с памятью: «NPC забывают» — главная боль жанра; адаптивные
  системы заявляют +43% D30 (jenova.ai «AI Life Simulator», Seele AI).
- Поколенческие симы: генетика, наследники, соперники, шаринг «истории жизни»
  (Sentience, Genworld, MyLife — r/LifeSimulators).
- Роглайт-мета: забег умирает — мета остаётся; престиж = добровольный сброс за
  постоянный бонус; сезонный трек платит в мета (Heroic Labs «Meta Progression»;
  bugnet.io «Roguelite Meta-Progression»; ONI «Prestige/Rebirth»).
- Telegram-социал: лидерборды +25% ретеншена; сквады/рефералы/шаринг —
  вирусные механики; урок Hamster Kombat: пик без удержания пуст (pixelplex.io;
  Reown «Top Telegram Mini Apps 2026»).
- Карточный свайп = универсальный язык жестов («навигация = действие»),
  онбординг не нужен (Swiper Studio; AppCoda; swing/gajus) — наша колода
  попадает в тренд.

## P1 — большие переработки (дизайн + код)

- [x] **P1.1 Мета-ресет «Новая жизнь»**: после финала карьеры (`POST /api/game/new-life`) — рестарт
      с дня 1, а переживают ресет: ledger `meta` (жизни, воспоминания-финалы, лучший грейд, глубочайший
      день, действия за все жизни), ачивки, Stars-покупки/бейджи, стрик входа. Мета-множитель
      `metaXpMult`: навсегда +15% XP за каждую жизнь, потолок +75% (5 жизней) — встроен в `xpGain`.
      UI: карточка финала показывает бонус и двухшаговую кнопку «Начать жизнь N» (5с отмена);
      меню показывает «жизнь N» у «Продолжить». 11 unit-тестов движка. Косметический «скин-воспоминание»
      как предмет комнаты — отложен до арт-решения (P2: cNFT/трофеи).
- [x] **P1.2 Сезоны/ивенты по времени**:
      `content/sprints.json` — 3 темы вращаются по реальным неделям (Пн–Вс, UTC+3, та же таймзона,
      что у чек-ина). Чистый движок `shared/engine/sprint.ts`: окно недели, ротация тем, прогресс по
      префиксам действий, doneJustNow, клейм раз в неделю (16 unit-тестов). Сервер: прогресс в
      `/action`, вью в `/state`, `POST /game/sprint/claim` с гвардами (активная неделя + все цели +
      один клейм; «награда сгорела» — если неделя закрылась). Клиент: карточка `SprintCard` в «Дне»
      (таймер, метры целей, кнопка награды). Живой прогон: спринт «Неделя прокачки» +12 000 ₽,
      повторный клейм отклонён. Офферы-события со сроком действия — отдельной порцией позже.
- [x] **P1.3 Архетипы-билды навыков**: «Путь фронтендера» и т.п. — готовый маршрут по галактике
      с бонусом за завершение; подсветка маршрута на карте.
- [ ] **P1.4 Коллекции-сеты в доме**: «Ретро-уголок», «Кибер-спальня»… — за набор даётся малый

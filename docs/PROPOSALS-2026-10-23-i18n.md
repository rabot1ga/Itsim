# P2.5: i18n (EN) — инфраструктура словарей, этапы (23.10.2026)

Статус: **этапы 1–2 реализованы** (инфраструктура + клиентские строки +
переключатель языка + серверные сообщения). Перевод контента — этап 3 (механизм + не-event слайс готовы, события/интервью — батчами).

## Расхождения с ожиданиями

1. **Тексты в коде** — да, все ≈2300 строк UI+сервера живут литералами в
   TS/TSX; словарей не было вообще.
2. **Одно «кодовое» место — не один текст**: шаблонные строки с интерполяцией
   (`\`Мне ${n} лет\``) должны стать параметризованными ключами.
3. **Модульные константы** (`const LABEL = 'Джун'`) вычисляются при импорте —
   «живое» переключение языка без перезагрузки ломается на них. Решение:
   смена языка **перезагружает приложение** (стандарт для Telegram Mini Apps);
   все модули пересобираются под новый locale.

## Дизайн (этап 1)

- **gettext-стиль, ключ = исходная русская строка** (`t('Мой день')`). Не нужно
  изобретать стабильные id, миграция механическая, непереведённые строки
  отображаются как есть (fallback = ключ). Шаблоны — с плейсхолдерами
  `{name}`: `t('Мне {n} лет', { n })`.
- **Ядро** — `packages/shared/src/i18n/`: `t(locale, key, params)`,
  `getStoredLocale()/setStoredLocale()` (localStorage `itsim.locale`, дефолт
  **`ru`** — продукт RU-первичный, e2e и юниты полагаются на русский; EN —
  явный выбор пользователя), словарь `en.ts` (RU→EN), `coverage()` для отчёта.
- **Клиент** — `lib/i18n.ts`: `t` под текущий locale, `useT()`, смена языка =
  запись в localStorage + `location.reload()`.
- **Кодмод** — `tools/i18n-extract.mjs` (TypeScript AST): оборачивает
  кириллические литералы/JSX-текст/шаблоны в `t()`, добавляет импорт,
  пропускает тесты, ключи объектов, импорты, строковые типы, enum-инициализаторы
  и `case`-метки (последние — в отчёт для ручной правки). Инструмент
  переиспользуем на этапе 2 (сервер) и при доработках.
- **Конвертер шаблонов**: `` `Мне ${n} лет` `` → `t('Мне {n} лет', { n })`
  (идентификаторы — по именам, сложные выражения — `p0`, `p1`…).

## Этапы

1. **(сделано) Клиент**: ядро i18n + кодмод по `client/src` (без тестов) +
   словарь `en` для всего UI-хрома + переключатель RU/EN в настройках +
   `i18n:coverage` + тесты. Русский текст не изменился (ключ = исходник) —
   e2e и юниты не тронуты лексикой.
2. **(сделано) Серверные сообщения**: локаль запроса — заголовок `X-Locale`
   (клиент шлёт выбор) → `language_code` из Telegram initData → `ru`.
   AsyncLocalStorage + обёртка route-хендлеров (`onRoute` в `index.ts`) —
   параллельные запросы с разными языками не смешиваются; `t()` в
   `server/src/lib/i18n.ts`, словари общие (`@itsim/shared`). Кодмод
   (`--import-ext=.js` для NodeNext) — 199 обёрток в 17 файлах; словарь EN
   дополнен серверными ключами (итог: 822/822, `i18n:coverage`). Сообщения с
   контентом (названия событий) — только на этапе 3. Примечание: язык не
   персистится в сейве — его несёт каждый запрос; поле в профиле имеет смысл
   добавить на этапе 3 вместе с локалями контента.
3. **(частично) Контент** + human-тексты движка. Уточнение дизайна: вместо
   файловых оверлеев (`events.en.json`) — **тот же gettext-словарь** (значения
   контент-JSON = ключи): механизм, fallback и coverage уже работают, загрузчик
   и схемы не меняются. Перевод применяется на границе API (`onSend` →
   `translateDeep` для всех JSON-ответов) + `t()` авто-переводит строковые
   параметры (имена контента внутри сообщений) + `dt()` для display-текстов
   движка (вычисляются в браузере: `checkEndings` и др.). Кодмод-строки
   shared обёрнуты `dt()` с параметризованными ключами.
   Сделано: механизм + весь не-event контент (items/companies/projects/skills/
   balance/achievements/perks/challenges/sprints/archetypes/npcs + ключи
   движка, 331 ключ). Осталось: события (~1400 строк), вопросы интервью (321),
   длинные тексты — отдельными батчами; `i18n:coverage` отчитывается отдельно
   по коду и контенту.
4. **Локализация форматов** (даты, числа, плюрализация `Intl.*`) — когда
   появится второй язык с другой грамматикой (EN — терпимо без неё).

## Риски и решения

- **e2e/юниты** ищут русский текст: дефолт `ru` + ключ=исходник дают побайтово
  тот же UI — ничего не ломается.
- **Замороженные константы** модулей: перезагрузка при смене языка (см. выше).
- **Смешанный EN** (частичный словарь): допустимо на этапе 1, EN помечен
  «beta» в переключателе; `npm run i18n:coverage -w packages/client` честно
  показывает долю переведённого.
- **Цитаты/кавычки** в строках: кодмод экранирует через JSON.stringify.

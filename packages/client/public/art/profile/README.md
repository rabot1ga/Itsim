# Профиль: портреты настроений

Три баннера «карточки жизни» (решение 22.10.2026, вариант A): тот же протагонист,
что в story-v1 и финалах, но в одном из трёх настроений. Внешность не
кастомизируется — настроение выводит `profileMoodOf()` из энергии, мотивации и
выгорания (`packages/client/src/lib/profileArt.ts`).

| файл          | настроение | когда показывается                          |
| ------------- | ---------- | ------------------------------------------- |
| `normal.webp` | В ритме    | энергия выше трети шкалы, мотивация ≥ 25     |
| `tired.webp`  | Усталость  | энергия ≤ трети шкалы                        |
| `burnout.webp`| Выгорание  | `burnoutDays > 0` или мотивация < 25         |

## Провенанс

- Мастер-PNG сгенерированы 22.10.2026 (бюст 4:3, палитра story-v1: тёмный
  hoodie, очки, ночной монитор) и лежат вне git: `artifacts/profile-moods/`.
- Публикация: resize 512×384 (cover), WebP q82 — те же параметры, что у тиров
  комнаты (`public/art/room/`).
- В git попадают только `.webp` и этот README.
